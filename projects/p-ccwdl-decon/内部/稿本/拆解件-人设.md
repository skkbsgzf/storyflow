# 拆解件 · 人设（character 槽）

> 人物卡原型拆解：魂躯复合主角、对手镜像与关系网，含替换变量表与盖名测试记录。

## 一、主角原型卡：「枭雄卑躯」复合体（archetype 候选）

**模式**：强魂弱壳——内核（魂）与外壳（躯）的反差即人物装置；两篇范文共用。

**三维（埃格里）**
- 生理【壳】：五短身材、短手粗指、揉面茧（范文一 §1）——劣势一笔带过，立刻转技能证据。
- 社会【壳×魂】：最底层小贩身份 × 帝王级眼界与名望记忆；市井舞台（清河县/阳谷县三条街）。
- 心理【魂】：负天下之志 + 被塞进最受气皮囊的荒诞感；反应不是自卑是好玩（「曹操忽然笑了」）。

**人物真相（压力下的选择，麦基）**
- 被砸摊/被催工时，选「记账/反要价」而非忍让或报案——揭示真身（范文一 §5；范文二 §3）。
- 面对原局死劫名词（潘金莲），选「笑」——态度宣言即真相剧透（范文一 §2）。

**维 = 矛盾**
- 内矛盾：杀伐决断之魂 × 必须笑脸营生的壳——每场戏都在「想掀桌」和「只能递饼」之间拉扯。
- 塑造反差：全城最弱的外形 × 全县最深的耳目（范文二 §4）。

**为什么一定是他（辩证证明）**：只有曹操兼具「成事方法论（情报/品牌/挟令）+ 不在乎丢脸的心态 + 对原局所有人的降维了解」——换任何穿越者都玩不转「把炊饼摊做成情报网」。

## 二、专属语言记录（盖名测试样本）

- 「回去告诉你家主人，想见我，拿东西换。」（短句、命令式、要价结构——强势方语言，遮名可判掌权者）
- 「我有的——他做梦都想要。」（停顿补刀，权力自陈）
- 「你说，这饼该谁吃？」（反问收尾，把选择权甩给对方=施压话术）
- 词域：商业（秤/账/买卖/换）+ 官制（连坐/作证/令）双域混用；压力下变短、变问句。

## 三、对手卡：西门庆式地头蛇（给对手一把刀）

- 欲望：吞下主角的营生与女人（原局既定）。
- 方法：钱 + 官面关系（管家/衙门人脉）+ 市井暴力（砸摊）。
- 学习适应：范文二 §5 被反制后改走「管家夜访」暗通道——对抗力量随主角行动升级（原文事实）。
- 镜像关系：与主角同吃市井规则这碗饭——主角的盾（情报/合法性）恰是他的刀（人脉/砸摊），同源克制，打脸有杠杆。

## 四、关系网（卫星人物，全部为主角的维服务）

| 人物 | 模式 | 功能 | 溯源 |
| --- | --- | --- | --- |
| 邻人/街坊 | 信息出口 | 点破身份；「街坊都看见」= 民意证人库 | 范文一 §1；范文二 §3 |
| 王婆式撮合者 | 墙头草 | 两头吃酒 → 行踪成为主角的第一件武器 | 范文二 §3 |
| 潘金莲 | 原局死劫 | 只闻其名未见其人（两篇共识）——留作第二幕引擎 | 范文一 §2；范文二 §2 |
| 县衙/都头 | 合法性来源 | 排队买饼→传证作证，权力倒转的秤砣 | 范文一 §4；范文二 §5 |

## 五、可复用模板 + 替换变量表

**模板**：{强魂}×{卑躯}复合体；真身揭示=压力下选{魂之招牌动作}；对手={地头蛇}（钱+官面+暴力三件套）；关系网={信息出口}{墙头草}{原局死劫}{合法性来源}四件套。

| 替换变量 | 取值示例 |
| --- | --- |
| {强魂} | 曹操 / 刘邦 / 武则天（方法论型枭雄皆可） |
| {卑躯} | 武大郎 / 店小二 / 赘婿（市井最底层营生者） |
| {魂之招牌动作} | 记账 / 定价 / 结盟（一句话能立方法的动作） |
| {地头蛇} | 西门庆 / 把头 / 帮派管事 |
| {原局死劫} | 潘金莲案 / 原作必败局 |

**使用条件**：跨书/跨代穿越的市井开局；失效条件——{强魂}无成事方法论（只剩权势记忆，无法落地为营生技能）。
