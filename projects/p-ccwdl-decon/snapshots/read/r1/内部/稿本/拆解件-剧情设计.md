# 拆解件 · 剧情设计（plot-design 槽）

> 设计层拆解：两篇范文对照五行、类型判断与结构公式，含替换变量表与使用条件。

## 一、概括五行（两篇对照）

| 行 | 范文一《炊饼里的魏武》 | 范文二《阳谷县没有忠臣》 |
| --- | --- | --- |
| 梗/元素 | 枭雄魂穿卑躯（魏武之魂 × 炊饼担），身份反差即卖点 | 奸雄穿卑躯 × 市井情报网，记「人账」替代武功 |
| 人设模式 | 强魂弱壳：内核枭雄（负天下），外壳全城最弱（武大郎） | 同壳异法：不走强攻走经营，笑脸+热饼收耳朵 |
| 事件切入 | 醒来见担子→邻人一句点破身份（半炷香对上号） | 穿越第七天只记账（动作切入，先立方法论再立冲突） |
| 钩子/期待 | 潘金莲名字触发笑→「卖天下人没吃过的饼」→西门庆管家上门被反要价 | 拆帘改矮门（改既定死局）→砸摊者被记账反制→西门府管家夜访矮屋 |
| 关键节点 | 翻面（产品革命）→三日断市→七日官府排队→狮子楼买卖开局 | 记账→拆帘→反制砸摊→县衙传证→西门府暗通（权力倒转五步） |

## 二、类型判断与核心情绪

- **类型**：历史人物穿越 × 市井翻身流（跨书穿：三国魂 × 水浒局）。
- **核心情绪**：**爽（反差兑现）**，辅情绪为**疑**（读者等原局死劫——潘金莲/西门庆——如何被奸雄解法拆解）。两篇共性：爽点全部来自「身份反差的兑现场」——用最弱的皮囊做最强的事，旁观者震惊即爽感来源（原文事实：范文一「三日全县炊饼摊没了生意」；范文二「知县断案开始传炊饼摊的矮子作证」）。
- **情绪承诺**：欺负这个「矮子」的人，每集都要为低估付账。

## 三、结构公式（两篇归一的类型骨架）

```
苏醒错位（强魂验弱壳，身体喜剧一拍）
→ 立方法论（把原主绝活换成枭雄技能：炊饼=产品/账本=情报）
→ 反预局（原作死局道具被拆解改写：挑帘竹竿落空）
→ 首次公开兑现（市面碾压/公堂作证，旁观者视角拍震惊）
→ 强敌接触（西门庆式地头蛇递话，主角反要价）
→ 收束钩（地下交易/权力倒转成立，暗示更大棋盘）
```

## 四、可迁移结构要点（共性，非单篇读后感）

1. 【原文事实】两篇开局都不写穿越过程，落在**物件特写**（担子/账本）上——穿越即刻物化为可执行的营生。
2. 【合理推断】「原作死局」是本类型天然的第二幕引擎：读者带着原著名场面期待（挑帘/毒饼/狮子楼），作者逐个改写兑现=持续爽点供给。
3. 反派（西门庆式）强度设计：钱+官面关系，恰好被「市井情报+官府合法性」克制——对手的刀和主角的盾同源（都吃市井规则），打脸才响。
4. 卑躯不卖惨：身体劣势一笔带过（手短三寸），镜头立刻转「怎么用它」（揉面茧=新技能证据），反面清单——不写自卑内耗段。
