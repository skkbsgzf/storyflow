# 去AI味诊断单 · r1（四遍法）

- 第一遍·声口：钱有德「程序呢」两次出现为设计性口头禅，保留；郑局长台词全部带官腔拖音，遮名可辨，无需动刀。
- 第二遍·处境：王婶送鸡蛋、老周拍复印件，身体反应先于台词，处境落在物上（鸡蛋/复印件/测尺），无需动刀。
- 第三遍·比喻意象：明喻 3 处（筛/春蚕吃叶子/给谁数着拍子），密度约 0.8/千字，限额内；「像一道闸」收尾与题材互文，保留。
- 第四遍·节奏机味：「突然/仿佛/似乎」全文 0 处；「不是A是B」0 处；三连排比 0 处；破折号 2 处（限额内）。
- 实质修订 3 处：①第1章签字场面补一拍集体反应（有人把签好的承诺书挪远）——公式「反应衬托」加密；②第2章「在线人数从三百跳到三万」改为递进两级（三百→四千→三万），涨势更真实；③第3章「念完他自己先笑了」句前补「袖口还在滴水」——身体先行，收放更稳。

- 增补修订 4-6 处：④「水真的在涨」改「水是一寸一寸上来的」；⑤「复印件确实旧了」改「是旧了」；⑥章末新增三行——通报悬置（钱有德灯亮一夜）+「下一个不吃文件的陈默还会在吗」向前问句钩。
