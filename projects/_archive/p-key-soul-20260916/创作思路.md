# 创作思路页（小纲 · 拍魂 · run p-key-soul）

> 本页说明前三集"为什么这么写"。客户批注时请对照各集分镜——意见落在具体分镜上，修改才能落准。

## 第一集《捡拍》——为什么这么开场

- **用"扔东西"开场，不用打球开场**：第一拍是搬家扔旧物，不是球场英姿。原因：这部剧的爽是"被低估的人翻盘"，所以必须先让观众看见"被扔掉"的是什么——一支锁在箱底的老球拍。扔的东西越不起眼，后面越贵。
- **英灵在 B0002 就开口**：不做悬念拖延。《棋魂》同构的核心钩是"器物里有人"——这钩子越早亮，观众越早入局。憋到第二集只会让前九拍变成普通的贫穷戏。
- **藏了两处**：①英灵听到"王守拙""老街"后沉默五秒（他知道发小的家，但不说）；②爷爷起夜两次路过王拾房门（他发现箱子被动了）。这两处是暗线的第一对钳扣，第 25-30 集揭盅时回收。
- **反差人设在 B0008 立住**：全校最横的人在爷爷面前只说四个字。"横"和"孝顺"必须同集出现——分开放就散了。

## 第二集《入队》——为什么让他这么招恨

- **睡袋、躺接球、41% 出勤**：故意的。主角前期越不把训练当回事，后面"为爷爷认真起来"的落差才越大；同时这些行为把全队的仇恨值拉满——观众每看一集被打脸，都会想起"他自己也懒过"。
- **王锐直播点名放在集末**：大反派的第一次出现不用他本人登场，用直播间的一句话——居高临下、但还没使坏。这保留了"他只是个被运营出来的花瓶"的喜剧空间，也把市联赛的期待值拉满。
- **郑伯的位置**：他不是队里的人，是圈子的记忆。他送胶皮、说"有人要成精了"——老一辈开始注意到主角，是主角被"圈内承认"的第一步（这一步故意来得早，因为主角技术上确实早熟）。

## 第三集《双王》——为什么第一场大戏是市联赛

- **双王同姓是结构性设计**：王拾与王锐都姓王，粉丝圈自然撕裂成"锐王党/真王党"——"真王 vs 姓王"的梗不是硬塞的，是从人物设定里长出来的。这场戏负责把这个梗立起来。
- **半决赛打削球大爷**：故意安排一个无恩怨的对手——证明主角的"听声"绝活对任何打法都成立，不是只在戏剧冲突里才灵。同时大爷那句"耳朵是真功夫"是圈内的背书。
- **王锐先胜一局**：hot 档也需要一次真实挫折——粉丝声浪干扰发球是环境性的、不涉黑幕的挫折，符合"没有幕后黑手"的整体设计。翻盘方式（把耳朵借给英灵、只听球）是主角与英灵信任的第一次兑现。
- **结尾爷爷认出打法**：全剧暗线第一拍正式落地——爷爷不认识孙子赢了什么，但认出了那个发球姿势。这是"拍魂"两个字第一次被点亮，也是观众必须带着进下一集的问题：爷爷到底知道多少？

## 前三章整体节奏

- 爽点密度：4/4/4（每集递增一个"情感爽"补充"动作爽"）
- 仇恨值来源刻意分散：队长（规则）、胡凯（出身）、王锐（流量）——三种不同的看不起，为三种不同的打脸预留位置
- 两处克制：王拾没有对家人炫耀；英灵没有解释自己为什么消失——这两个"不说"分别是明暗两条线的燃料
