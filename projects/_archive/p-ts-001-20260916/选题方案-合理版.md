# 选题方案 · 合理版：《守堤人》（水利版 · run p-ts-001）

> 设定来源（C10）：实事新闻底子（防汛/工程质量终身责任制/国债水利项目），自造专名 0 个

## 一、项目背景

**频类/题材**：男频 · 都市 · 逆袭 · 主旋律（受控词表：主"逆袭"+副"都市/行业/主旋律"）

**剧名候选**（网感公式标注）：
1. 《守堤人》（主推——身份+意象，深沉档调性）
2. 《这道堤，我不签》（反常+承诺，5 字）
3. 《洪峰来之前》（倒计时悬念）
4. 《三十年巡堤日志》（金手指+承诺）
5. 《全县都在签字，只有他拒签》（对照反差）

**世界观（实事底子）**：虚构的青川县，青川河穿境而过。堤防除险加固国债项目落地，全县工程链条动员：承包商赶工期、监理走过场、验收要体面。规矩是三十年没变过的规矩——"国债项目、专家评审都过了，你一个人懂什么？"而规矩之外还有一本账：二十年前青川河溃口，抢险牺牲七人，其中一人的责任认定书写着"操作失误"——他叫周长河，是周正的父亲。**这套世界观没有一条需要解释的规则：堤、水、签字、责任，观众全懂。**

**选题理由**：空白垂类首例（水利 n≈0）+ 全民共识底子（防汛/工程质量/吹哨人三重公共议题）+ 倒计时结构（汛期）自带节奏收紧。对标《老炮开山》（65000 万，一技之长+被无视的当众翻盘）与《扫地姑娘》（94000 万 · A+，隐藏实力验证结构）。

## 二、故事梗概

周正，58 岁，青川县河道管理站工程师，守青川河大堤三十年。手插堤土知含水，耳贴堤身听管涌，站里人称"水底下的耳朵"。堤防加固国债项目验收那天，全场签字，只有他拒签："垫层少二十公分，反滤层省了料。"第二天他被调去守最偏远的泄洪闸。没人知道他为什么这么倔——二十年前青川河溃口，抢险牺牲的七个人里，那个被写成"操作失误"的，是他父亲周长河；而当年真正指出隐患的报告，从档案里被人抽走了。主汛期倒计时，他带着三十年巡堤日志把全堤 217 处隐患重新走了一遍。洪峰预警那夜，他把隐患图越级抄送市防指，签下拿三十年名誉担保的疏散令。洪峰过境，日志上标过的险位逐一应验，周家坳零伤亡。表彰会他缺席——堤上，他把父亲的遗像朝河面摆了摆：**那份迟到了二十年的报告，今天替你交上了。**

## 三、核心人设（8 名有名角色，C5 合规）

**周正**：男主，58 岁。工装、胶鞋、一只帆布包（日志在里头）。话少，句子像验收记录。绝活：手插堤土知含水，耳贴堤身听管涌。口头语："先看土。"（专属语言卡：名词+动词，从不用形容词；越急越慢。）
**周禾**：女儿，24 岁，县水利局新入职，被"打招呼"分去档案室。全剧暗线的钥匙——缺页的旧报告，是她一页一页找回来的。
**赵立行**：反派（前中期），52 岁，水利局副局长。当年溃口事故的施工员，如今主管加固工程。"不是我要压你，是这堤经不起翻旧账。"
**钱广进**：反派（执行），45 岁，加固标段承包商。"规范是死的，水位是活的。"
**郑伯**：70 岁，退休老站长，周正的师父——当年事故的见证者，守口如瓶三十年。钥匙人物："有些话我答应过你爹不带进土里。"
**苏晓**：28 岁，监理员——唯一在报告上写真实数据的人，被全行业孤立。年轻一代良心线。
**秦振国**：50 岁，县防指指挥长。主旋律接口："表彰会你可以不来，堤你得帮我看着。"
**周长河**：父亲（遗像与闪回出场），二十年前的巡堤工，溃口抢险牺牲。

## 四、大纲与冲突设计

**主线骨架（五节点价值链）**：
1. 【拒签】验收会当众拒签 → 代价：调守泄洪闸+女儿被打招呼（尊严+亲情双重代价）
2. 【建档】巡堤重走 217 处隐患 → 获得：日志=预言书（金手指显形）
3. 【验证】周家坳管涌前兆上报被压，三天后应验（公开性升级：县里有人开始信）
4. 【越级】洪峰预警夜，隐患图越级抄送市防指（不可回头点：与全县工程链公开决裂）
5. 【危机选择】洪峰夜管涌群：签疏散令（若无事=造谣追责；不签=堤毁人亡——两难均有代价）→ 高潮：反滤围井抢筑+日志应验 → 结局：零伤亡+旧报告回档（父亲正名）

**冲突层次（≥3）**：外在（汛期抢险与时间赛跑）/ 社会（工程质量链条与问责制度）/ 私密（"父亲的死到底怪谁"——他守堤三十年的心结）。

## 五、后续剧情走向
