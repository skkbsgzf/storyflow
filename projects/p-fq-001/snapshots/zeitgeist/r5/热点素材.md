## 一、结构核（v3 结论压缩保留）

舆论场三方权力关系，正是「大排档被抹黑」第一卷的战场骨架：

- **主播/大V（舆论祭司）**：框架权——「这家店食材有问题」一句话给全城食客的舌头装滤镜；生产资料=人设，收益=话题度
- **吃瓜群众（燃料库）**：易被煽动且知道易被煽动；生杀权无程序；从众推理链被大V预热——「大家都说有问题→那应该真有问题→我也不去了」
- **商家（卡牌塔匠）**：口碑塔一张张搭、一句话塌；反制只有慢刀；连火力从哪来都看不见

最锐利的不对称：**造谣即时零成本，自证永久被动**。第一卷的「抹黑食材风险→平反」就是这个结构的一次完整攻防。

## 二、新素材层Ⅰ：思维链可见，对三方关系的改写

主角异能=看见所有人的**思维链**（大模型式推理全程：`让我想想 → 调用工具 → 得出结论 → 深度思考`）。这不是读心——读心读结果，思维链读**过程**；而现代社会操控人心的本质，就是往别人的推理过程里塞开头。

| 三方 | 思维链可见后暴露了什么 | 爽点来源 |
| --- | --- | --- |
| 祭司（造谣者） | 造谣是条**流水线**：「让我想想今天黑谁 → 调用工具（PS检测报告/买水军） → 得出结论（发布）」——主角看得见台词本 | 抢读剧本：反派还没出手，主角已看完他的完整作案计划 |
| 燃料（群众） | 从众推理链全程可见：「大家都说难吃 → 那应该是真的 → 我也这么说」——**每个人的想法都是环境投喂的** | 逐链翻转的爽感；看清「想法被安装」的瞬间 |
| 匠人（商家） | 自证困境的根源可见：食客嘴里说「不敢吃」，思维链里却是「其实想吃但怕被笑话」——嘴和脑是两套推理 | 主角的平反不靠辩解，靠改写环境：让人群自己「重新推理」 |

**主题落点（用户红线）**：想法易被操控、环境影响舆论——在设定里物理化为两条世界观规则：①思维链会被环境改写（天气/热搜/大V定调=给全城推理链塞同一个开头）；②水军的思维链是 AI 批量生成的**同款模板链**（含机量 99%）——造谣产业本身就是 AI 产业。思维链战争 = 人脑推理 vs 模板链的攻防。

## 三、新素材层Ⅱ：AI 梗异能体系（用户映射表 · 聚合落位）

世界观层（模板文化）：超能力者以模型拟人化为金手指（本体）、哈内丝（harness）为专武。用户提供的社区映射表逐条落位：

| 术语（用户映射） | 世界观含义 | 消费点 | 去向 |
| --- | --- | --- | --- |
| Model = 角色本体 | 每个异能者的本体是某个模型的拟人娘 | 主角本体=吃白饭的鲸鱼娘（开源体：便宜、量大、深度思考强、饿得快）；反派可用闭源贵妇系 | Bible 角色体系 |
| Harness（哈内丝）= 专武 | 异能者的武器/终端 | 专武形态各异（键盘/终端/指令刃）；水军的哈内丝是廉价批量款 | Bible 装备体系 |
| Sonnet→Opus→Fable / Luna→Sol→Astra = 升命座 | 晋阶体系 | 晋阶仪式=「版本发布」；卡在命座的憋屈与突破 | Bible 等级体系 + 卷结构节点 |
| Skill = 圣遗物 | 技能模块，可掉落装配 | 开源社区=圣遗物刷取副本（GitHub 本）；awesome 列表=圣遗物图鉴 | 章纲 B 线玩法 |
| Prompt = 轴 | 言出法随的咒语 | 念错轴=技能空放；轴的质量决定输出 | 正文场面梗 |
| Context Window = 轴长 | 记忆长度 | 轴短的角色记不住三天前的事（喜剧点+战斗弱点） | 配角设计 |
| Thinking Effort = 凹轴程度 | 深度思考档位 | 凹轴=烧元石的豪赌；主角深度思考时的世界「慢镜头」 | 战斗体系 |
| Token = 元石 | 货币/能量单位 | 说话就烧钱——话痨异能者穷得快（阶层梗：穷人舍不得深度思考） | 世界观经济+阶级讽刺 |
| 5h/Week Limits = 体力 | 使用限额 | 大战打到一半「这周体力没了」——平台限量的荒诞 | 战斗反转梗 |
| Subagents = 二/三号位 | 分身/组队 | 主角开小号群聊式作战 | 玩法扩展 |
| Benchmark = 深渊强度 / Real-world = 大世界强度 | 考试型 vs 实战型 | 「深渊满星、大世界躺平」的考试型反派（刷题强的水军头子实战拉胯） | 反派讽刺位 |
| Sandbox = 空气墙 | 结界/试炼场 | 决斗在沙盒里打，赢了也没奖励（打工人加班梗） | 场景设计 |
| Temperature = 双暴 | 玄学暴击属性 | 调高温度=随机暴击/当场发疯；稳态输出 vs 玄学暴击流派 | 战斗变数 |
| 模型智力 = 天气 | 全局环境 | **主题级设定：全城智力随天气变化**——舆论 Storm 天，所有人的推理链集体降智（环境影响想法的物理化） | 世界观核心规则 + 卷末大事件 |
| 模型迭代 = 版本更新 | 世界更新事件 | 新版本发布=全城异能者洗牌，有人升命座有人被 deprecated（35 岁危机梗） | 卷结构驱动事件 |

**聚合说明**：这套体系的可玩性来自「AI 术语 × 原神式养成框架」的双层熟悉感——AI 从业者认术语梗，二次元玩家认养成梗，两头梗储量都是全民级。天气/版本更新两条是结构级设定（驱动卷事件），其余按场面梗/台词梗消费。
