## 一、选题

**选题名**：《守堤人》。封面标题（口语化、有冲突感）：**「全项目部都在签字，只有他不签」**；备用封面标题：「这单我不签」。

**一句话定位**：大堤除险加固验收在即，全项目部只有 58 岁的老总工一个人不肯签字；后来，洪水替他验了一张没人敢验的收据。

**时代情绪锚**（当下社会情绪 + 30 天内证据）：

> **较真者的憋屈 × 汛期防洪焦虑**——认真的人在系统性糊弄面前孤军奋战，而堤的那头是千家万户的身家性命。

- 底层情绪（普适长期）：「会干的不如会混的」——每个观众身边都有一个「不肯签字的老工程师」和一个「签得飞快的人」。
- 顶层焦虑（实时）：汛期未过，「堤里有没有猫腻」的愤怒是进行时。证据：2026 全国「质量月」25 部门联合部署、严查偷工减料弄虚作假〔A 级，2026-09-04〕；台风「沙德尔」登陆、最高级别洪水应急响应启动〔A 级，2026-09-03〕；8 月中旬河南某县堤防决口与封堵的全民围观长尾〔B 级，2026-08-13〕。
- 合规注：真实灾害只作情绪举证，剧内事件独立成案（虚构的临江圩除险加固工程），零对应、零影射、零伤亡消费；剧内台风一律无名（只称「台风」「上游雨带」）。

**新意装置**：**拒签单 × 洪峰当众验证**——「他没打赢任何人，是洪水替他赢了」。装置改变的具体写法：

- 清算执行者由主角的嘴置换为水位：他只负责留痕，宣判交给洪水。改变 E10 的写法——验收会死局（他被反咬立案、被「请」出会议室）不由他自辩，由雨后第一轮涨水在管涌现场替他对数；改变 E53 的写法——终局反转不是反转人，是同一水位把同一条堤分成两半（一堤两制）；改变 E58 的写法——清算名单不用查，就是他自己重抄的那一摞拒签单，一页对一段，逐页念。
- 金手指 = 权力型制度身份（签字权 / 复审权 / 终身责任制条款），每次使用带成本：拒签一次，岗级掉一层。爽点一律锚「拒签 × 洪峰验证」机制，零财富皮。

**核心爽点承诺**（一句话）：看一个被全项目部孤立的老头靠一张一张「不签」活到最后，看洪水把他签过的和没签的堤段当场分成两半——**他写下的每一页，都会回来收账。**

**开篇 3 秒设计**（第一拍具体画面与台词）：

验收会议室长桌俯拍，签到笔沿十几只手传递、逐个落名，签得最快的是监理负责人；笔传到秦江海手里——停。特写：笔帽在图纸桩号上敲三下。他念桩号不看人：「3+820 到 3+960 段，堤身填筑压实度不合格，要求钻芯复检。**这单我不签。**」全场回头，笔悬在半空。

- 反常（唯一不签的人）+ 冲突（当众拦验收）占全，零铺垫、零背景交代。
- 生理测试：没看过背景的人听完这拍不问「为什么」，只问「然后呢」——过。

## 三、冲突设计

**韩剧强度基准自检**（对标近 3 年复仇 / 豪门剧的情绪浓度）：

- **情绪直接饱满**：不写克制隐忍。三槽引擎保证每集 ≥3 个外化爆点——台词槽（拒签三要素金句）、对撞槽（四件套施压 → 物证回击）、碎片槽（身份碎片 / 物证特写 / 水位 tick）。长剧把「较真者被碾碎」拍三集才给一次反击，本剧受辱与第一击回敬同场完成。
- **反杀当场化**：羞辱与回敬时差 ≤2 拍（E3 为范式：撕稿 →「撕吧，每一页我都抄了三份」= 时差 1 拍）；大胜留给集尾卡点。
- **金手指 = 权力型身份**：兑现画面是可拍的权力动作——水位线对照、联签单作废、责任状落笔、执业资格吊销、刻名碑，不是「证明自己是对的」。
- **反派连坐**：恶人是一张签字链，拆解有顺序有仪式（返工自费 → 吊证移送 → 逐页拆签名 → 审计封条）。

**主线冲突（一句话）**：不肯签字的老总工要在洪峰到来之前，拦住一整条想把问题堤段「合法签收」的签字链。

**单元冲突模板（可无限复制）**：「**一张验收单 = 一次攻防**」——反派用四件套之一施压（先签后补稀释责任 / 隐蔽工程不留影像 / 拿防汛窗口期压质量 / 把提问题的人调岗边缘化）→ 秦江海用物证或制度条文回击（芯样、渗压记录、水位线、责任条款）→ 集尾卡点收。可复制原因：分部工程天然逐项验收，一张单 = 一集节拍；变量池 = 反派四件套 × 验证物 5 种（钻芯样 / 渗压读数 / 留样标记 / 水情日志 / 水位刻度），4×5=20 个变量，60 集不重样；全部攻防装进三景（验收会议室 / 堤段工地含汛期堤坡与堤头闸房 / 项目部办公区含资料室仓库角），换景 = 换集。

## 四、大纲（三段式，名场面具体到画面）

### 前期（E1-30）：拒签立状 → 首卡验证 → 调岗闸房 → 开膛销项
