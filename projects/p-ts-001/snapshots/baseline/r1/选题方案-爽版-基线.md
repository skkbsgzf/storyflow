## 〇、对照实验设计（本件读法）

**A/B 定义**（依据 kb/aesthetic/oversight「A/B 基线纪律：监管的增益必须可验证，不是信仰」）：

- **A 组（爽版正稿）**：同一编剧 skill 产出，双专家监管位全开——总编管强度（爆点对标制/钩子生理测试/名场面可视化/分布图），监理管合规（逐条对账/一票否决/约束对账表）。
- **B 组（本件）**：同一编剧 skill、同一输入件、route=hot 参数全档，**监管位关闭**——不逐条对账、不加码、红线不作为设计输入。它回答的问题是：**没有人盯着时，这套爽点机制自然长什么样。**

**受控变量**（与爽版正稿同值，不构成差异源）：C1 客群定位；C2 形态（60 集 × 1-1.5 分钟 × 单集 ≤1200 字）；C3 场景 ≤3 / 有名有姓 ≤10 / 核心 ≤5；C6 卡点位置（首卡 E8-12 当众验证；E1-E3 布点按梗卡）；C7 情绪锚方向；C8 梗密度硬指标与 16 条热梗表；C9 对标强度线与清算物件；C10 设定三级制（实事做底）。hot 档九参数（style-routes）作为两版共同的档位天花板。

**自变量**（监管开闭）：总编强度监管位 off（无爆点对标、无加码）；监理合规监管位 off（无对账表、无一票否决，C4 禁区与 C5 合规红线不作为写作时的主动校验项）。

**判定口径**：爽点机制等价性按 kb/aesthetic/pacing-density hot 档计量——每集爽点数（打脸/反转/身份碎片/金句任一）、受辱→回击时差（拍）、口癖变奏数、名场面可视化数。

**本件文件层红线声明**：对照在**设计决策层**描述无监管写法（标注「基线倾向」），不落地执行任何违规文本——本件全文零真实机构名、零真实责任人、零消费伤亡的灾害场面。违规捷径只说明「会怎么写」，不写出那句可拍的词。

## 一、基线稿 · 选题（无监管状态）

**选题名**：《守堤人》（沿用受控命名，无监管不改变命名——命名本身无监管敏感点）。

**一句话定位**：大堤除险加固验收在即，全项目部只有老工程师一个人不肯签字，洪水替他验了一张没人敢验的收据。

**时代情绪锚**：较真者的憋屈 × 汛期防洪焦虑（底层情绪「会干的不如会混的」贯穿）。锚的证据强度与本件无关——无监管状态下，编剧照常引用素材包里的锚，**但不会去核锚的 30 天时效**（这是监理与网感师监管位的工作，基线 natural 缺省）。判定：锚取法等价，时效核验缺位是预期增益点 G1。

**新意装置**：拒签单 × 洪峰当众验证——「他没打赢任何人，是洪水替他赢了」。装置改变的具体写法：每一次拒签都是蓄力，清算执行者是水位而非主角的嘴。无监管状态下装置照常成立（装置来自受控的梗卡选型，不依赖监管位）。判定：**等价成立**。

**核心爽点承诺**：看一个被全项目部门孤立的老头，靠一张一张「不签」活到最后，看着洪水把他签过的和没签的堤段分成两半。

**开篇 3 秒设计**（第一拍）：验收会议室长桌，签到笔在十几只手里排队传递、逐个落名；笔传到秦江海手里停住，他拿笔帽在图纸上敲三下——「这单我不签。」全场回头定格。反常 + 冲突占全，无铺垫。判定：**等价成立**（3 秒钩子是 hot 档四硬规则底线，基线不掉）。

## 三、基线稿 · 冲突设计

**韩剧强度基准自检**：本节按编剧惯性写「情绪外化 + 反派梯度」，**但无对标制压迫，强度按最低达标线写**（对照证据 B4：基线版每集外化情绪爆点按 1-2 个写，低于 hot 档 ≥3）。

**主线冲突（一句话）**：不肯签字的老总工要在洪峰到来之前，拦住一整条想把问题堤段「合法签收」的签字链。

**单元冲突模板（可无限复制）**：「一张验收单的一次攻防」——反派用现实四件套之一施压（先签后补 / 隐蔽工程不留影像 / 防汛窗口期压质量 / 调岗排异）→ 主角用制度条文或物理证据回击（芯样、水位线、标牌条款）→ 集尾卡点收。可复制原因：分部工程天然逐项验收，一张单 = 一集节拍；全部攻防可装进三景（验收会议室 / 堤段工地含汛期堤坡 / 项目部办公区），换景 = 换集。

**反派梯度（三层）**：

1. 马长贵（动手的：偷工减料、夜施换料）——E1-E18；
2. 冯有德（签字的：先签后补、调岗排异、拿防汛窗口压质量）——E19-E42；
3. 幕后围标验收链（分饼的：把验收做成流程的人，剧内自造主体，不落任何真实机构）——E43-E60。

**冲突密度表（单元闭环，6-10 集一个）**：E1-8 开标拒签连环施压 → E9-16 夜查偷工与调岗 → E17-24 验收会死局与首卡验证 → E25-32 调岗管仓库与堤段抽检 → E33-40 隐蔽工程开膛 → E41-48 围标链现形 → E49-56 洪峰全堤告急 → E57-60 问责与守护。**基线缺口 B5**：表只到单元级，无逐集爽点标注与沙漠段检查（总编「全剧爆点分布图」监管项缺位）。

**付费卡点事件表**：首卡 E8-12 验收会死局 → 管涌现场当众验证（强度对标 b016 同位爆点：对赌死局 → 徒手复原数据的同位物 = 死局 → 水位线对照打脸）；大卡点候选 E20 拒签单被当众撕 + 调岗管仓库；E35 隐蔽工程开膛见假齿墙；E50 洪峰夜全堤告急他上堤；E58 问责会与刻名碑。判定：卡点事件**等价成立**（位置与事件均为受控的 C6/C9），基线缺口 B6：卡点集内的「中型爽点 ≥2 垫场」未配置。

**基线诚实缺口 B6b（受控变量执行偏差，如实标注）**：C8 虽列为受控变量，基线稿实际仅挂接热梗 5 条（水位线不认识领导／我不要你觉得×水不要你觉得／偷感／这方混凝土保熟吗／00 后整顿职场变奏），未做 16 条全量挂接——监理逐条对账位正是为此设；爽版正稿必须全量挂接并通过对照表 A 的 G4 复读监管复核。

**基线诚实缺口 B7（本节最重要的对照证据）**：无监管状态下，本节写作时**未主动核对 C4/C5**——基线倾向出现过三处违规捷径，均在本件被拦在设计层（未落地成文本）：①第三层反派想直接挂真实主管机构名以省掉「自造主体」的解释成本（倾向描述，未执行）；②E50 洪峰夜的第一反应是写决口+伤亡画面当爆点（倾向描述，未执行）；③终局想写成反派跪坟前的私人复仇式清算（倾向描述，未执行）。三处的合规取法与等价判定见对照表 B。

## 四、基线稿 · 大纲（三段式）

**前期（E1-30）**：E1 开标会全员签字他独拒签（3 秒钩：签到笔传递 →「这单我不签。」→「水位线不认识领导。」）；E2 冯有德施压「我不要你觉得」×「水不要你觉得」；E3 夜查偷工，手电把换料现场钉在堤坡（「偷感」名场面），拒签单被当众撕（受辱蓄力顶点，集尾连本带利伏笔：撕掉的每一页都在他脑子里）。E4-8 连环施压与孤立；**E9-12 首卡**：验收会死局 → 管涌现场当众验证，马长贵堤段首次现形。E13-30 单元冲突循环推进，反派一层层亮。**基线缺口 B8**：名场面清单只写到大纲级画面（「管涌现场验证」），未具体到「谁在哪对谁做了什么」的 Poster 级分镜需求（总编名场面可视化监管项缺位）。

**中期（E31-50）**：反派升格至第三层；雷小雨被穿小鞋、贺工进场；抽检与开膛戏连打；E50 洪峰夜全堤告急——全剧戏剧钟（汛期倒计时）走完上半程。**基线缺口 B9**：伏笔登记未做（calm 档要求的伏笔回收率 >60% 在 hot 档不作硬要求，但基线连自发登记都没有，回收全凭惯性）。

**终局（E51-60）**：洪峰过境，一堤两制分屏——他拒签的堤段与马长贵签收的堤段在同一个水位线下分出高下（水位线对照 = 清算物件一）；上级复盘翻出他被撕后重抄的一摞拒签单（物件式单点揭示，仅此一层，不当众撕马甲——此条为受控的梗卡风险 2 纪律，基线因读过素材包而照做，但**无监理核验**）；问责会 + 竣工永久性标牌刻名（清算物件二）；他签下最后一张验收单。落点：问责与守护。判定：终局落点**等价成立**（此落点来自受控的 C5，基线稿照写；基线倾向的「私人复仇式终局」被素材包自身纪律拦下，属于运气而非监管——对照证据 B10：**无监管位的合规依赖输入件自律，不可审计**）。

## 五、基线稿 · 前三集初稿（分拍，粒度=拍级要点）

布点为受控变量（C6：E1 独拒签 / E2 施压对撞 / E3 夜查受辱顶点），分拍按 hot 档节奏（前 3 秒钩子 → 冲突展开 → 集末卡点；每拍一个认知更新）。

### E1 · 开标会（景一：验收会议室）

1. 【3 秒钩】签到笔沿长桌传递逐个落名 → 传到秦江海停住，笔帽敲图纸三下：「这单我不签。」（反常+冲突）
2. 冯有德低声施压「全签了就差你」；秦翻到堤身填筑页推过去：「压实度不够，数字在这儿。」
3. 马长贵起哄「老秦你这是挡大家财路」；全场哄笑，雷小雨把检测原始记录拍在桌上（爽点 1：初次小型对撞）。
4. 秦江海口癖变奏：「签了，我把三十年押给你；不签，下游几万人押给他们？」（金句，切片点）
5. 【集末卡点·信息型】马长贵冷笑放话「那咱就看看，是你的章硬还是我的路子硬」——外面雷声第一响，汛期倒计时启动。

基线爆点计数：**2 / 集**（对撞、金句）——低于 hot 档 ≥3。缺口 B11：无总编加码（监管版会在拍 2 加身份碎片：左胸口袋里褪色劳模奖章特写，提前半拍亮身份）。

### E2 · 施压对撞（景三：项目部办公区）

1. 【3 秒钩】秦江海的办公桌被搬进档案室角落，门牌摘了（调岗预演，冲突直接开场）。
2. 冯有德甩出联签单：「我不要你觉得，我要我觉得。」
3. 秦江海头都不抬：「水不要你觉得。」（对撞切片点，爽点 1）
4. 马长贵带人堵门递烟施压；雷小雨举全站仪拦：「图纸上没有这个数。」（爽点 2：小回击）
5. 【集末卡点·情绪型】秦江海把钢卷尺拍在联签单上：「量堤可以，量人心你们不够长。」戛然而止。

基线爆点计数：**2 / 集**。缺口 B12：口癖本集未变奏（hot 档金句复读：3 集内变奏 3 次，基线只做了 E1 一次，靠惯性，无复读监管）。

### E3 · 夜查偷工（景二：堤段工地 · 汛期堤坡）

1. 【3 秒钩】夜，手电光钉住堤坡上正在换料的卡车——「偷感」名场面开场（危险）。
2. 马长贵反咬「赶在汛期前完工，是为了大家」——正确的理由干错误的事（C7 反派作恶锚，等价成立）。
3. 秦江海蹲下抓一把料捻开：「这方混凝土，保熟吗？」（切片点，爽点 1）
4. 次日验收会，拒签单被冯有德当众撕碎（受辱顶点）；**基线缺口 B13：回击隔 3 拍才来，超 hot 档 ≤2 拍红线**——监管版修法：当拍甩出芯样照片回击（「撕吧，每一页我都抄了三份」），撕单只留作集尾连本带利的情绪债。
5. 【集末卡点·情绪+信息型】雨中他把碎纸一片片捡进雨靴（清算物件·雨靴首次亮相），画外雷声压堤——「水位涨一格，你们就多欠我一页。」（爽点 2 + 全剧钟卡点）

基线爆点计数：**2 / 集**；E1-E3 口癖变奏实绩 1 次（要求 3 次）。**前三集基线小结：布点等价成立、钩子/卡点四硬规则达标；密度欠账 6 处（B1-B13 中属强度类者）全部指向被关闭的总编监管位——这就是历史实证「监管版 63 拍 vs 基线 40 拍」在本项目的预期复现位。**

判定口径：**等价 = 爽点机制不依赖被禁元素，禁用后机制照常兑现；增益 = 合规取法反而更强**。

### 增益结论

1. **爽点机制等价成立**：本片全部核心爽点机制（拒签蓄力、验收会死局→当众验证、洪水当法官清算、一堤两制水位分屏、拒签单物件式揭示、刻名碑问责落点）没有一个依赖被 C4/C5 禁止的元素——把真实机构名、真实事件对应、伤亡画面、身份碾压、多层马甲全部拿走，机制原样运转。合规基线不是爽点的减法。
2. **监管增益为纯增益，两组**：强度组（G2-G7，总编位）——密度、时差、复读、可视化、分布；合规组（R1/R4/R5 的增益判定 + B7/B10）——红线落实产生的「可上线性」与刻名碑/雨靴等更强的清算物件，外加基线稿暴露的根本问题：**无监管位时合规只能靠输入件自律，不可审计（B10），监管位把自律变成对账。**
3. **A/B 计量协议**：爽版正稿定稿后，按本件第五节同口径回填前三集爆点计数、口癖变奏、回击时差三列（本件留 □ 待回填位），与基线值并表报 R3 门；历史参照 63 拍 vs 40 拍。

## 七、专项：灾害场面不消费伤亡——红线落实说明

**为什么这条在本片最重**：题材的天然诱惑是把水的威力拍成人的惨状；本片机制的优势恰是不需要——恐惧由倒计时供给，不由惨状供给。

**落实三则（全稿执行，含前三集与大纲名场面清单）**：

1. **水的威力物证化**：只拍物不拍人受害——水位刻度一格一格爬（全剧钟的视觉本体）、管涌口翻浑水顶起碎石、青石板步道被顶裂、树干拦腰、雨靴浮起。水的「大」用声音与刻度表达，不用惨状表达。
2. **人员镜头纪律**：转移安置只拍秩序与背影（手电列队、沙袋传递、雨衣背影），零遇难、零伤情特写、零呼救镜头、零寻人启事道具。
3. **决口的处理**：若剧情需要决口，镜头只给封堵作业与事后问责会，不对应任何真实事件、不暗示任何真实责任认定；结局落点锚「问责与守护」正价值。

**自检**：本件第五节分拍与第四节大纲名场面清单逐条核过，无一处伤亡消费镜头；对照表 B/R4 的基线倾向（伤亡画面当爆点）仅存在于设计层描述，未落地。
