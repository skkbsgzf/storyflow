# 世界观 · 《今夜开闸》

清源县，北方傍水小城。1958 年建的水库设计寿命五十年，超期服役。东闸是唯一泄洪通道，闸房墙上挂着三代闸工的照片——陈守闸是最后一代。
县城权力生态：水利局是「没出息单位」，预算年年垫底；维保外包养着关系户；真正的规则是「不出事」——不出事 = 没有故事 = 安全。这条潜规则养出了两种人：装睡的，和被当成疯子的。
98 年那场洪水是全城集体记忆的伤疤：有人殉职，有人受处分，报告语焉不详。从此「报险」成了禁忌词。
