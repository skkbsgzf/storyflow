## 失误与根因

- 提交后读 state.json 出现两次竞态误判（flow_submit 落盘与读秒差），导致对 m2.plot-choreographer / m2.script-forge 各多打一次 submit，收到 409 NODE_NOT_AWAITING，无状态损伤。根因：脚本链里 sleep 不足 + 以 grep 过滤掉了 submit 的关键回执。修正：以 registry/artifacts.json 的 sha/round 为准复核，不依赖时序敏感的 state 读。
- serve.py 首启 --tunnel 的 URL 正则误抓 cloudflared 报错行里的 api.trycloudflare.com（假阳性"已通"）。根因：正则只认域名形态不验语义。处置：弃用其内嵌隧道，改为手动 cloudflared 并以端到端 curl 验证（带码 302 + 401 门 + 页面字节）。
- trycloudflare 大文件传输在 QUIC 下断流、http2 下爬速，public 分享不可用。处置：给 serve.py 加文本类 gzip（625KB→245KB，4 秒可拉全页），顺手保留原 no-store 语义。此为共享工具增强，已语法校验+端到端回归。
