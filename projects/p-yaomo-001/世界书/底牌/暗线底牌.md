# 暗线底牌（作者专用·永不入正文）

1. **长公主底牌**：姜月初=昭月长公主。总司文书叮嘱魏合"礼不可废"；她拒绝三进三出宅子、坚持"都司只有指挥使"。本剧只亮给观众一次（集2 密谈），剧中人知情范围：魏合知，旧部不知，反派死也不知道。
2. **百妖谱全貌**：击杀结算/回卷存妖/驱妖部署/录妖夺神通四则全貌只存在于主角脑内。集1 暗开场可用"妖尸崩解回卷"一拍点术不明说；集2 靖妖坊一拍她查谱自语（只给半句）。
3. **夺灵秘术的来路**：忘痴从葬仙关带来秘术——他与葬仙关的关系是续篇钩子，本剧不揭。
4. **清算顺序的私心**：姜月初把围山拖满三日，不是犹豫，是等全陇右的镇魔卫到齐——要当着整个陇右的面拆牌（人物动机，只可在其台词里露半句："三日，一个都不准放走"）。
5. **数值口径**：道行结算字幕（击杀获得道行 N 年）为本剧唯一超自然 UI，样式统一白字浮层，全剧一致。
