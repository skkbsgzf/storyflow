# 世界书纪律（剧本变体）

> 体系标准：knowledge/continuity/worldbook.md ｜ 结算单位：**集** ｜ 状态机：draft → active → retired（不删档）

## 章回结算五件（每集交稿后、下一集派发前）

1. 章卡/集卡（一句话+梗点+钩型+新名目）→ 分集账/集账.md
2. 人物状态推进（伤/钱/知情/关系/位置）→ 人物/*.md（当前状态改写+变动史追加）
3. 交接（下一集写手必知的 3-5 条）→ 分集账/集账.md 末节
4. 伏笔变动（新埋/回收/顺期）→ 伏笔/台账.md
5. 世界揭示（本集确立的新设定事实）→ 设定/*.md

## RAG 规则（写第 N 集的开工动作）

1. 读 index.json 按 tags 拉词条（不重读全书）
2. 读 分集账/集账.md 末节（=上一集 handoff）
3. 读伏笔台账中 open 且临近回收的条目
4. 底牌按节点号取段，禁止整读

## 变体特例

场景卡联动有名场景≤3 硬约束；道具卡管连续性信物；与 词汇表.json 并行（词汇表管专名安全，世界书管设定真相）
