# 选题素材 · 曹操穿越武大郎

## 甲方点子
曹操（三国最强枭雄）魂穿北宋武大郎（最卑微的炊饼郎）。反差感拉满：从"宁教我负天下人"到"三文钱三个炊饼"。

## 核心爽点
用兵法做炊饼（阵法布局烤炉）、以权谋待客（分化和瓦解地痞）、挟天子以令诸侯 → 挟口碑以令市集。

## 暗线
武大郎原本有个不为人知的秘密——他不是普通的卖炊饼的。他的死不是意外。曹操的到来，恰好落入了别人布了十年的局。

## 三章试稿
第1章：穿越 + 第一个反差（枭雄灵魂在卑微躯壳里醒来，用军法整治欺凌他的泼皮）
第2章：炊饼生意的"军事改革"（阵法烤炉 + 分销网络 + 口碑战）
第3章：武松归来，发现哥哥变了——试探、对峙、暗流涌动
