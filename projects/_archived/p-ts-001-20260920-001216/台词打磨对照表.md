## 四、三遍校准记录

### 第一遍 · 人物声口（遮名抽测）

- 秦江海：抽「3+820 到 3+960…」「不信，钻一管土上来，一量便知」「他们欠了一笔——签了字，就生利息」——先给数字后给判断、只陈述不恳求、把账算到涨水那天；遮名可辨 ✓
- 马长贵：「挡大家财路」「章硬还是路子硬」「跟你吃肉」——递烟江湖腔，无书面语串味；每处错误选择都有他的理（汛期前回款）✓
- 冯有德：「表决」「再研究研究」「你自己掂量」——句句往程序与人多后面躲，最狠一句也裹着「为你好」的棉花；阴柔成立 ✓
- 雷小雨：「图纸上没有这个数」×2＋封样双份——只认数据，年轻不虚；「声音发紧，脚不退」处境注在 ✓
- 桂守成：「程序上，就差这一笔了」——流程腔 ✓
- 结论：无串味；未做「为特色而特色」的加戏，老实处的平句（工人甲一句）保平 ✓

### 第二遍 · 处境校准（压力级-句长反向）

- E1 验收会议室（高压·当众）：秦全短句陈述；冯压低声音只七字「全签了，就差你」；表决段台词退化到单词句（「表决。」）✓
- E1 堤坡（独处·低压）：「老伙计」放软——对堤不说对人，同一人两种温度 ✓
- E2 档案室（孤立·中压）：对空屋说「这一单，我还不签」，说给空屋子听比说给人听更硬 ✓
- E3 夜查卸料点（危机）：省略主语「几点了，还在卸料」；E3 受辱当场句最短——「撕吧。」两字起手，压力与句长反向成立 ✓

### 第三遍 · 去AI味（24 类＋结构指纹）

- 词句层：命中并修 3 处（对照表 #1／#2／#3，均解释独白／填充语／书面残迹）；标点归位 1 处（#5）；其余台词未命中损害性条目。
- 结构指纹：对白回合非对称（冯七字对秦长句；马哄笑—雷拍记录的打断式进出；冯「再研究研究」答非所问式撤退）；同一人物连续台词句长错落；全稿无新增排比抒情、无三段式 ✓
- 解释残留扫描：剩余专业信息均由物件与动作承载（钢卷尺咔声锁死、快测滴一声、撕纸声独占两秒、存档联半秒特写），无向观众报幕句 ✓
