# 网文手法与编排速查（p-fq-001 内部·蒸馏版）

> 蒸馏自参考书系（大王饶命/第一序列/诡秘之主/武动乾坤/凡人修仙传/末日乐园/异常生物见闻录等）的公知手法——不做像素级拆书，只留三件：**编排习惯、梗的手法、名目密度**。拆书线简化：书单保留为参照，原文到手后只提炼手法三件套，不再走六槽位全流程。

## 一、章节编排惯例（前 30 章的行规）

1. **黄金三章**：第 1 章立人设+金手指现形+第一个笑点；第 2 章金手指第一次实战见效；第 3 章第一次当众打脸（有观众、有前后对比）。
2. **章内节拍**：承接上章钩（两行内）→ 事件推进 → 小爽/小笑点 → 章末大钩。开场禁止回忆、禁止写景。
3. **爽点密度**：三章一小爽、十章一大爽；**压抑连续不得超过 2 章**——主角可以被嘲，不能连续吃瘪。
4. **金手指解锁频率**：每 5-8 章一个新用法；新用法出现后 3 章内必须**变奏复用**一次（不活化=白给）。
5. **装逼打脸四件套**：当众 / 有观众 / 有前后对比 / 打脸有代价或后遗症（无代价的爽不值钱）。
6. **单元节拍（5 章单元）**：2 章铺垫压抑 + 2 章爆发 + 1 章收割（收人头/收名声/收资源）。
7. **预告式钩子**：章末钩尽量带「下一章的具体期待」（某人要来/某事要发），不做纯氛围钩。

## 二、梗的七种手法（成熟梗「进设定」，老套梗「进台词」）

| 手法 | 定义 | 本书应用 |
| --- | --- | --- |
| 反差 | 身份/能力/外形的错位 | 全废土最丢人异能=顶点神的崽 |
| **变奏** | 同一梗重复出现但每次换个马甲（变奏才是梗的成熟态） | 饭勺认错七变奏（见大纲名目表） |
| 复读 | 口头禅/固定句式的仪式化 | 「一口饱不了」「先吃再说」 |
| 错位 | 一本正经地说傻话/严肃场合干傻事 | 神殿评定书把神写成厨具 |
| 打脸 | 先抑后扬，当众兑现 | 验毒宴/评定日 |
| 数值 | 量化羞辱与量化凡尔赛 | 元石余额/含机量读数/供品三十息 |
| 联动 | 前章伏笔后章回响（梗的复利） | 「巢」→第 26 章寄养凭据→第 30 章回家 |

**判据：梗进设定（成为世界观黑话，读者能学）= 成熟；梗停在台词（说完就完）= 老套。**

## 三、名目密度（网文味的核心）

网文的「味」一半来自**名目密度**：境界有名、招式有名、等级有名、黑话有名、耻辱有名。名目=读者社区的入场券（读者用你的黑话说话=书活了）。

本书名目表（新增，进 w-slang 词条）：

| 类 | 名目 | 说明 |
| --- | --- | --- |
| 神殿评定 | **天/地/玄/黄**四字，每字三品 | 潮生评定=「**黄字叁号·辅兽型（厨具类）**」——官方盖章的耻辱名目（命名梗变奏主轴） |
| 鲲崽成长四阶 | **漂 → 游 → 鲲 → 鹏** | 漂（饭勺大小，浮在盆里）→ 游（桶大）→ 鲲（吞船）→ 鹏（吞云）——终局鲲鹏变 |
| 吞的三式 | **浅尝**（吞链看真相）/ **鲸吞**（吞攻击）/ **饕餮**（吞怪成长） | 招式名=玩法名目化 |
| 勺语 | 铁饭勺敲盆的节奏指令 | 一长两短=吞；急敲=回巢——饭勺从「认错」升格为「指令系统」（金铲铲梗的玩法化） |
| 废土黑话 | 含机量 / 食灵 / 退件 / 白嫖党 / 辅兽 / 开饭号 / 大断代 / 智祭怪 | 读者能学走的词 |
