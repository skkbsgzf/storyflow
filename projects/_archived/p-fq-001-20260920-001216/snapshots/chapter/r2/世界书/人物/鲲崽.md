# 鲲崽

## 核心档案

- 蓝色、圆滚滚、懒——觉醒日被潮生认成饭勺；神讳**北冥鲲君**之崽（民间只叫大肥鱼）
- **要**：干饭（合成膏吐掉，只吃真饭和怪——废土最后一个美食家）
- **怕**：没饭；被问「免费的代价是什么」
- **能力**：吞三式本体（浅尝/鲸吞/饕餮）；认勺语（妈妈的铁饭勺：一长两短=吞，急敲=回巢）
- **神格**：慵懒抠搜白嫖成性；深潜全城最快；偶尔漏口风（**漏口风三规则**：松弛时漏/只漏脚注/漏完岔开）
- **暗线位**：鲲君下在废土的「押金兼种子」（底牌 w-secret）；寄养凭据刻在铁饭勺柄（「北冥鲲君·养」，落款=大断代元年）
- **成长四阶**：漂（现）→ 游 → 鲲 → 鹏（鲲鹏变）
