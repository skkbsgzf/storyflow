# 文风档（本书声音规范）

## 一、一句话定义本书声音

**「账本体的废土童话」**——像一个小饭馆老板在废土上记账：账目冰冷，账本里夹着神话。

三个关键词：**记账**（万事可计价，情绪也记账）、**废土的冷**（世界不答应任何事）、**灶台的暖**（人情的暖只在吃饭时给）。

## 二、叙述基准

- **视角**：第三人称贴身限知（潮生）。信息=潮生所见+鱼泡。禁止上帝补课（不能写潮生不知道的事）。
- **时态**：现场进行地讲——每一段都是「正在发生」，不是「发生过」。
- **段落**：1-3 行为主。**单句成段=重锤**，每章 2-4 处，只砸在真相和转折上，不许随手砸。

## 三、句子节奏（治「平」的核心药方）

- 短句（≤7 字）占比 ≥40%；
- **连续三句等长必拆**；连续两段同一节奏模板必换；
- 三段式节奏：铺垫（可长）→ 转折（短）→ 落锤（更短，名词句最佳）——落锤示例：「祭台上空，征收令。」
- 「的」字连用 ≤3；形容词堆叠 ≤2；每章「突然/仿佛/似乎」合计 ≤2。

**「平」的病根只有一个：用总结代替场景。** 每句概括性的话，都必须翻译成一个有声音、有动作、有价码的画面再落笔（见 §九样张）。

## 四、声口规范（人物=声音）

| 人 | 声口 | 校准例句 |
| --- | --- | --- |
| 潮生 | 短、账本体、嘴笨 | 「记账。」「饭勺。」 |
| 鲲崽 | 吐泡文，懒，两三字 | 「加钱。」「巢。」 |
| 陈母 | 金句+生意腔+市井量词 | 「在我家灶台垫脚，是它八辈子修来的福分。」 |
| 陈大海 | 半截话+动作代话 | 「不是异能。是祸。」 |
| 尖嘴哥 | 语速快、见风转舵、职业腔 | 「消息换口粮，童叟无欺。」 |
| 执事/神殿 | 官腔+表格词 | 「器型：厨具？」 |
| 雷臂 | 骄傲转敬、短促 | 「你家雷炒面。」 |
| 水军哥 | 散谣顺口溜腔（张口带韵，散谣职业习惯），怕死怕得具体 | 「你们知道我以前给谁干过活吗？……见人就笑。」（单元 2 定腔：散谣词押韵，与尖嘴哥的见风转舵拉开——v9 评审备查转正） |

判据：**遮住名字，三句内认出是谁**。认不出=声口不成立，改。

## 五、幽默方式（只准三种）

1. **错位正经**：大词说小事——官方表格写「器型：厨具？」；
2. **降维实诚**：神话事物用市井逻辑接——神谕=零嘴，神崽=加钱；
3. **预期违背**：前文铺足 A 的期待，落地给 A-1——抬着担架来赴宴，一口饭，担架先坐下了。

禁：网络烂梗直贴、谐音硬挠、旁白解说式玩梗、贫嘴连珠炮。

## 六、比喻系统（语料域白名单）

比喻必须出自**角色生活域**：灶台/海鲜/账本/海潮/渔网/腌货/秤。
例：「征收令没了……像嗑瓜子」✓。
禁：出戏的文艺比喻（「如同深渊吞噬大地」类）；废土人口中蹦科技词（潮生看链时的系统词除外）。

## 七、情绪段规则（真段落）

- 情绪真段落：**零梗**、放慢、允许一个 ≤25 字的长句收尾；每章 1-2 处，多了腻；
- 落点永远是「人」，不是「景」——写爸爸的袖管，不写废土的黄昏。

## 八、交稿前十条自检

1. 开头两行是事件或反常，不是写景；
2. 遮住名字，三句内认出说话的人；
3. 删光「突然/仿佛/似乎」，读感不降才算过；
4. 无连续三句等长；
5. 无超过 5 行的段落；
6. 梗全在对话/情境里，旁白贴梗=打回；
7. 情绪真段落零梗；
8. 章末钩是具体期待，不是氛围；
9. 本章至少动用一个名目（勺语/黄三/含机量/吞三式）——名目用了才活；
10. **朗读一遍：想跳过的段落，就是平的段落——重写那里。**

## 九、校准样张（平 vs 味）

**病样（平·总结体）**：
> 觉醒礼上，众人都展示了自己的强大异能，只有陈潮生的异能是一只蓝色的鱼，看起来像一把饭勺，大家都嘲笑他，这让他非常尴尬。

**样张（味·场景体）**——取自本书第 1 章成稿：
> 别人头顶降火龙雷凤，他头顶降下一团蓝色圆滚滚——「啪叽」，栽进妈妈的面盆。他端详半天：「是个饭勺？」执事落笔：「器型：厨具？」连问号都是官方盖的章。

差别不在辞藻，在**信息交付方式**：病样是「告诉」（一句话总结了尴尬），样张是「上演」（镜头+台词+官方文件梗，读者自己笑）。全书所有总结句，都必须按此翻译成画面。

## 十一、时停体技法迁移（拆书炼化 v2 · 2026-09-17）

> 拆解《时停！》449 章所得（全案见 内部/时停体炼化报告.md）。逐条为「可直接抄进正文」的写法。

1. **好消息/坏消息模板**：铺垫长句 → 一句段落锤 → 复读确认 → 自嘲具体化（「一分钟够干什么的？泡碗面都不够」式）。
2. **拟声单段**：「砰！」「咕咚。」「滋啦。」独立成段——转场、惊变、节奏换挡（本书高频用：鱼咬/勺敲/雷进嘴）。
3. **两字转场段**：「第二天。」「外界。」——切场景不写过渡句。
4. **自嘲确认句**：「嗯，他的异能是一把饭勺。」——身份+黑色幽默一句双清。
5. **反讽词**：褒义词形容危险事（「青礁聚落民风淳朴，就是隔三差五死人」）。
6. **夸张数字梗**：「引发了一亿点小小的骚动」。
7. **名目可见化**：重要名目用【征收令】【勺语】方括号标记（每章 ≤3 处，重要才加）。
8. **黑历史复读**：丢人语录被聚落传唱回响（潮生的丢人宣言/「黄三」诨名定期复读打脸）。
9. **高潮喜剧调剂**：紧张场面写配角丑态（水军哥式抽焦），高压段必须留泄压阀。
10. **格言透视句**：人情练达总结句，每章 ≤1（「认命和认输，就差一口气」）。
11. **章末钩零氛围**：全是台词/懵逼/倒吸凉气/半截动作——具体反应收尾。
12. **次章无缝续钩**：次章首段直接演上章末钩的反应，不重述。
13. **能力做用法乘法**：不加第二异能，把「吞」玩出一万种用法（时停=只玩一分钟的同款结构）。
14. **章名即第一梗**：双句梗章名（「好消息时间静止，坏消息一分钟」式）——章名先笑一次。

**开场七式轮换**（同式不连用）：人物状态单句 / 上章钩续接 / 冲突对白 / 拟声单段 / 两字转场 / 时间跳切 / 地点定场。

## 十二、开篇定场与读者认知（新读者官条款 · v3）

> 来源：用户判词「小说开篇完全没介绍世界观/背景/主角，读者不知道发生在哪」——冷 open 不能以读者迷路为代价。执尺人：**新读者官**（agents/first-reader.profile.json，零上下文首读者，评审前禁读大纲/圣经/底牌）。

**定场四问**（首章前 300 字交齐，缺一打回）：

1. **何时**——时代坐标一句话（本书：「神明降临第四十年」）；
2. **何地**——地点 + 靠什么活着（本书：青礁聚落，开祭日全村到场的海边废土聚落）；
3. **谁**——主角姓名 + 处境 + 想要什么（本书：陈潮生，18，海记食堂独子，嘴笨记账，全家赌他火系）；
4. **世界规矩**——核心规则一条（本书：献什么换什么，神收什么就还什么）。

定场必须**长在事件和对话里**（价目牌/台位费/狠话都是载体），禁说明书式倾泻。

**新设定词引入五手法**（每个新词首现必选其一）：

| 手法 | 例 |
| --- | --- |
| 场景演示 | 器型「厨具？」——执事当众登记 |
| 官方文书 | 价目牌「献双眼，得火」 |
| 人物一句话 | 「思维链供品，潮生懂：收的就是人一天里想的事」 |
| 用后即释 | 先见鱼吞征收令，后补「征收令=悬了四十年的神谕链」 |
| 刻意存疑 | 老人「不饿的神，怎么开了口」——角色也不懂，每章 ≤2 |

**读者认知边界**（断层双向定义）：

- 正文出现而世界书未登记的词 = 断层（agent 库库写、读者跟不上）；
- 世界书里有而没向读者介绍过的词，被正文当已知用 = 同罪；
- 执行：每章结算在章账记「读者此刻知道/不知道」（见 世界书/纪律.md 第七件），新词先登记再进正文（登记台账在 设定/名目与黑话.md）。

**去AI味·禁则清单**（OpenAI 官方 8 类，全清单见 kb/aesthetic/slop-list）：结论式收尾句 / 套话动词 / 提示性过渡（「值得注意的是」）/ 自问自答 / **假对比句「不是A而是B」每千字 ≤1** / 强调词（真的·确实）/ 自造复合概念词 / 模糊限定。词表双向：管输出也管提示词。交稿加检：a) 全章搜「不是…而是/…，不是…」计数；b) 删掉任何一句结尾的「总之/综上/这就是」试读，意思不变就删；c) 「真的/确实/其实」删一遍试读。

**排比配额与文书体豁免**（prose-scan 执行口径）：叙述层三连排比每章 ≤1、「不是A（而）是B」每章 ≤2（webnovel-fastfood 红线）。文书体（价目牌/布告/账目/链画面分格编号）的排比豁免条件=它本身是笑点或世界文书本体，且每章仅此 1 处；**定场区（前 300 字）不豁免**——开篇节奏是读者对本书的第一印象（2026-09-17 用户揪出价目牌三连后定此规矩）。机械层交稿前必跑 `python tools/prose-scan.py 章节正文/第N章.md`；语义层排比（管X叫Y 式）机器抓不全，归新读者官通读兜底。

**定场区三禁（2026-09-17 用户二次判词，铁律级，覆盖文书体豁免）**：定场段禁**否定句**、禁**排比句**、禁**破折号**。价目牌正文改为非排比呈现（「头一行字最大/底下那行稍小/第三行的字缩得最小」的版面递减本身就是世情：嗓子最贱连字都小）。叙述层破折号全文清零，仅两类功能性保留：歌谣断句（「火没等着端饭碗——」）、对话被打断（「白天的事——」）；「不是A是B」模板句叙述层清零，对话与泡文字引文内保留（「膏里不是毒，是料」属引文）。prose-scan v2 已加破折号计数（≤1/章）。

## 十、与既有约束的关系

负面约束照常生效：ai-trace 五指纹、24 类、快餐红线（句长抖动/排比配额/无总分总）管「不像 AI」；本档管「像谁」。两套叠用，缺一不可。
