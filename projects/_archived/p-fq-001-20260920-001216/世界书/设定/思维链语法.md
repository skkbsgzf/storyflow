# 思维链呈现语法（规则清单①定稿）

主角神恩=**看见所有人的思维链**。读过程不读结果（W-RULE-03）：不读记忆与隐私；链是过程不是结局，人可反悔。

## 呈现语法（正文视觉规范——可截屏优先）

- 链的样子：目标人物头顶悬浮的**半透明弹幕流**，只有主角（及同层次眷者）可见
- 四阶段视觉记号：
  1. 「**让我想想**」——链头冒一个白泡（决策起点：盘算、犹豫、起意）
  2. 「**调用工具**」——链中图标闪（小锤/放大镜/相册：查手机、使眼色、递纸条）
  3. 「**得出结论**」——链尾落锤定格（拍板瞬间：一句话、一个转身）
  4. 「**深度思考**」——整链变金色、多线并进（重决策；主角自己深潜时世界慢镜头）
- **糊链**：智力雨天/环境太吵时链变毛玻璃（W-RULE-04 联动）
- **模板链**（水军/AI 代写）：链条整齐得像复制粘贴，链头标**含机量读数**（99%）——一眼辨机器
- **双链**：嘴上一套（说出口的话）脑内一套（真链）——主角最狠的公开处刑素材
- **被读涟漪**：同层次被读时，被读者链面泛一圈涟漪、本人可感「被什么扫了一下」——反侦察的物理基础；高阶眷者可顺涟漪反读（主角「被看见」危机的规则依据）

## 吞结论细则（红方条件②·能力规则定稿）

- 鲲崽只吞「张嘴够得着」的链（目标须在近身范围/链正被「使用」中）
- 吞下的链在鱼腹消化，以「鱼吐泡」形式浮现结论——潮生可读泡，不直读原链
- **被吞者体验**：脑子「空了一瞬」（约一次深呼吸），随后链缓慢再生；对普通人反复被吞=记忆与智力永久损伤（废土恶行「食灵」）
- 潮生红线：只吞反派之链、同一条链不吞第二次、永不对普通人用

## 伦理边界（眷者公约条款，防偷窥流）

- 只开**与案件/冲突相关**之链；日常闲逛不读
- 看见他人隐私链必须「视同没看见」（公约第一诫）
- 违约代价：神恩降档 + 天梯局记录（第二单元起成为剧情压力源）
