# 献祭双轨制（W-RULE-06）

**神恩的代价是献祭，分两轨：肉祭换力，智祭换知。** 献出去的不回来。

## 肉祭（器官献祭）——废土的主流

| 献什么 | 得什么异能 | 废土面孔 |
| --- | --- | --- |
| 双眼 | 「以目为炬」火系 | 火者皆是盲者——瞎眼看火，火在心中烧 |
| 双手 | 「雷贯之臂」雷系 | 废土打手标配；断臂者掌雷 |
| 声带 | 音爆系 | 哑者之吼 |
| 脊椎 | 钢骨系 | 佝偻的铁人 |
| 心脏（禁忌） | 传说中的「王侯级」 | 无人验证——献心者没有活过一夜的 |

- 特点：一次献祭终身有效、力量直观刚猛；**上限=身上还剩多少零件**（献完即顶，无法再强）。
- 社会面孔：显强系是废土的贵族与打手——也是满街的盲眼者与断臂者。**废土的强者谱系，是用残缺拼出来的。**

## 智祭（智能献祭）——全废土只有一位神收

- 只有大肥鱼（北冥鲲君）收智能：推理、记忆、判断、专注——token 化收走。
- 契约形式：daily 浮动采样（日常链）+ 深潜大额（用能力时的重税）。代价不可见、**无上限**（可以献到只剩本能）。
- 社会面孔：被嘲笑——「鱼连器官都不要，可见多废」。全废土智祭眷者寥寥，个个被当怪人。
- **反讽核**：肉祭可见且有限，智祭不可见且无限。废土谚语「宁可瞎眼，不可缺心」——没人说得清为什么，但所有人都这么传（w-secret：见过智祭过度者的老人不解释，只是不说——缺了心的人，已经不是人了）。

## 三条推论（结构的牙）

1. **零件封顶 vs 无底价**：肉祭者越强越残缺、且有天花板；智祭者看似免费、实则深渊——两种献祭，废土的两种人。
2. **海记=零献祭家庭**：陈大海只献过一只手，妈妈和潮生从未献祭——灶台烟火养出来的完整链，全废土最稀缺的「全须全尾」。
3. **诸神收祭的真相**：肉祭是死肉（w-secret：只能炼神体），链才是活粮——大肥鱼独走智祭路线，是它掉榜又回榜的秘密。

## 主角线绑定

潮生智祭的暗病=「先等链」（遇事不想先等鱼）；成稿红线：每次用神恩必须有献祭的自觉或代价，禁无代价开挂。
