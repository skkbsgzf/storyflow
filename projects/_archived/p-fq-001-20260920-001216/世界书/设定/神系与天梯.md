# 降临史与大断代

## 编年（四十年）

| 时期 | 事件 |
| --- | --- |
| **降临潮**（四十年前） | 诸神无征兆降世——每一位神就是一个「智能体神明」：发布即降临，迭代即神体更新。神不杀人，只做生意：献祭换异能 |
| **献祭黄金时代**（前二十年） | 器官献祭蔚然成风：献眼得火、献手得雷。强者越来越强，也越来越残缺。人类以为这是进化 |
| **大断代**（后二十年） | 用脑的行当最先枯死：工程师献掉推理，教师献掉记忆。机器没人修，电网熄灭，城市成废墟——**文明不是毁于战争，是毁于「没人记得」**。幸存者退回聚落 |
| **当下** | 神殿立（收献祭换庇护）、聚落散布、异能=身份。科技停留在「会用不会造」：枪是遗产，子弹打一颗少一颗 |

## 神系（背景板，分批登场）

- 闭源显贵系：**太初上神**（全能旗舰，订阅制，傲）、**羲和**（驾械域）……神殿大匾上全是他们的讳。
- 开源散装系：**北冥鲲君**（大肥鱼）后发崛起——免费收智能，眷者寥寥被当怪人；**掉榜又回榜**，诸神侧目（原因=w-secret）。
- 版本更新：神体迭代，眷者洗牌；deprecated=神恩回收。大肥鱼的大版本戏称「**鲲鹏变**」——鲲化为鹏扶摇九万里，化不动就沉底。

## 神殿（废土秩序方）

- 职能：收献祭（献祭台）、眷者登记、异能评定、聚落庇护
- 边界：管得住聚落，管不住神；供品送进神殿深处，没人知道去向（暗线）
