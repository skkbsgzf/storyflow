# 层稿 · 设定（防崩清单）

> 本稿用词全部在 World Bible 词汇表内，无世界书外新词；北宋市井名物按「用后即释」处理。

拍 #1
- 知情范围：何九叔知武大「变了」不知为何；武大知市集规则漏洞；看客只知新鲜。武大必须装傻——不能露出懂律法。
- 新词首现：店规（场景演示：木牌钉出即释）；月例（人物一句话自释：何九叔开口就是索要）。
- 台账增量：何九叔索贿未遂→记仇；店规木牌立起；看客围观成习。
- 人设揭示点：武大被按住钱袋不怒——压力下选择「立规矩不斗气」，与枭雄心性一致；何九叔留后门话（「管不管得了你」），油滑不崩。

拍 #2
- 知情范围：唐牛儿不知店规效力；众人不知武大身份。武大知唐牛儿背后有人但不说破。
- 新词首现：店规第三条（用后即释：白吃十倍）。
- 台账增量：唐牛儿欠三十笼；围观群体形成。
- 人设揭示点：唐牛儿拉人壮胆——欺软怕硬，与人物卡一致。

拍 #3
- 知情范围：众看客首次见证店规执行力；唐牛儿开始怕武大。
- 新词首现：无。
- 台账增量：唐牛儿按手印欠据；武大立信完成；「武大郎变了」的传言起头。
- 人设揭示点：武大罚而不辱（磨面抵账而非羞辱）——收人先用恩，权谋底色。

拍 #4
- 知情范围：市集知「限量」；无人知饥饿疗法的兵法来源。
- 新词首现：辰时（语境自明：清晨开卖）。
- 台账增量：炊饼品牌立起；明日开市预告。
- 人设揭示点：无重大揭示（过渡拍，疏笔合规）。

拍 #5
- 知情范围：武大知有半枚保书、不知内容（Bible 知情表：不知原主死因）；读者多知一步（纸背透印）。
- 新词首现：保书（刻意存疑：不解释用途，留钩）。
- 台账增量：F1 入武大手；原主「藏后手」印象建立。
- 人设揭示点：武大对原主改口「这怂货」→ 起敬，情绪微转不抢戏。

拍 #6
- 知情范围：何九叔知有人递钱；武大不知夜局；读者知盒盖印花。
- 新词首现：东家（称呼先行，身份存疑）。
- 台账增量：县吏-东家供养链咬合（读者视角）；「武大」标被仿用。
- 人设揭示点：何九叔掂盒熟练——贪而不蠢。

拍 #7
- 知情范围：武大知断供即危机；掌柜们知自己违约有靠山。
- 新词首现：粮行（语境自明）。
- 台账增量：面粉断供；三车三向（同盟三家的视觉化）。
- 人设揭示点：武大下颌绷而不语——先忍后算，与拍1一致。

拍 #8
- 知情范围：众人知有人囤粮；只有武大亮账。掌柜乙知风向可倒。
- 新词首现：市集信誉银（人物一句话自释：按店规折的违约金）。
- 台账增量：同盟裂；掌柜乙倒戈；毁约金入库。
- 人设揭示点：武大给弱者留活路（分化而非赶尽）——曹操「挟恩图报」式收人。

拍 #9
- 知情范围：伙计知掌柜夜里疼；不知疼因。武大知三限纪律（Bible 金手指成本）。
- 新词首现：三搭面（用后即释：醒面三次）、行军灶（场景演示：三堆火）。
- 台账增量：军粮方成；F4 登记在案（账本「三」字）；武大体力消耗。
- 人设揭示点：数火止疼——军中旧习，身份的生理性泄露（给武松线埋证据）。

拍 #10
- 知情范围：市集知新饼好；无人知配方来路。
- 新词首现：无。
- 台账增量：粗面饼立招牌；细面摊被压。
- 人设揭示点：无（爽点拍，干脆收）。

拍 #11
- 知情范围：白氏知保书全貌＋县吏把柄；丫鬟不知文书内容；武大与读者皆不知匣中物。
- 新词首现：无（「娘子/押司」宋称呼，语境自明）。
- 台账增量：F2 上弦；请托何九叔——供养链闭合。
- 人设揭示点：白氏抚印如抚伤疤——她与保书有私仇成分，不纯是利益（维=矛盾的种子）。

拍 #12
- 知情范围：武大知拘票构陷；伙计不知；何九叔知拘票来路。
- 新词首现：拘票（官方文书式呈现：朱印＋罪名即释）。
- 台账增量：武大被诉「私抬粮价」；画押系伪造（读者可推断）。
- 人设揭示点：武大看拘票先看折痕——从物证入手，不喊冤（权谋惯性）。

拍 #13
- 知情范围：武松不知内情，只见哥哥「能打」；武大知不能赢太狠（要留兄长脸面）。
- 新词首现：都头（武松身份，开场已带刀自释）。
- 台账增量：武力平手；武松起疑「背后高人」；武大虎口伤。
- 人设揭示点：武大收力让武松收拳——兄弟相认不能靠输赢（情绪线暗写）。

拍 #14
- 知情范围：武松首次入信息圈（账本/拘票/保书）；知情表更新：他知「有人构陷」，不知魂穿。
- 新词首现：无。
- 台账增量：F1/F2 交汇兑付一半；武松知情范围扩大（台账种子兑现）。
- 人设揭示点：武松捏纸指节白——怒的不是罪，是有人算计他哥（重亲缘，与 Bible 一致）。

拍 #15
- 知情范围：众看客见证对质；何九叔知大势已去；白氏远观全局。
- 新词首现：无。
- 台账增量：何九叔滑跪；定罪权当众反转；「店规第三条」开始口口相传。
- 人设揭示点：武松「先法后情」反向用——用法办贼护兄，人设双面成立。

拍 #16
- 知情范围：白氏知武大难缠升级；武大知背后是「东家」；双方互认对手。
- 新词首现：无。
- 台账增量：中点半揭完成（供养链/官眷味）；宣战成立。
- 人设揭示点：白氏挡嘴不挡眼——体面与毒辣同框（人物卡矛盾维可视化）。

拍 #17
- 知情范围：武松不知头痛底细；武大知三限已用二。
- 新词首现：无。
- 台账增量：佩刀交匾下（信任物化）；F4 小兑付；「孤」字差点出口——武松未察。
- 人设揭示点：武大改口「孤→我」——身份伪装的日常性滑动，压力下的自我纠正即人物真相；配角（武松）不抢戏，存在为刻主角。

## 尾部清单

**新词登记**（进名目台账）：店规 / 月例 / 保书 / 三搭面 / 行军灶 / 市集信誉银 / 拘票 —— 均已标注首现拍与释法；无世界书外私造词。

**伏笔登记**（设/收/转）：F1 设（拍5）→转（拍14）；F2 设（拍11）→半收（拍14/15）；F3 设（拍3-4 传言）→长线；F4 设（拍9）→小收（拍17）。无逾期项。

**时间线对表**：第1章一日（晨-夜）；第2章两日；第3章一日半。合计四日半，无「三天后」漂移。
