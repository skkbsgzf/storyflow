# 编排表 · 曹操穿越武大郎（三章试稿）

> 三章节拍：立规 → 断粮 → 查案。情绪曲线主型「层层递进」（赌注逐级抬高，无失衡级）；暗线「武大郎的债」：原主替人画押的保书在东家手里（F1 第1章埋、第3章半揭）。

## 主线骨架（价值转变链 × 双线拧紧）

激励扰动 = 索孝敬被当众顶回；不可回头点 = 断粮道反击战；中点（全弧第5集，试稿半揭）= 东家供养链曝光；危机选择 = 交出店规自证清白 vs 抗律到底（互不兼容、均有代价）；高潮 + 余波 = 武松对峙后的分工。危机加深线（泼皮→同行→县吏→律法）× 欲望加强线（守摊 → 立店规 → 控市集）逐章同时抬升。

## 三线装配（三章映射）

- **A 主线**：炊饼商战每章推进一格——立店规（第1章）→ 破封锁（第2章）→ 御状倒打（第3章）。
- **B 情感线**：兄弟轴。武松家书倒计时（每章一封，叮嘱「休惹官非」渐急），交叉点间距 ≤3 拍。
- **C 爽点线**：hot 档每章 ≥3 爆点 + ≥1 可切片梗点，布点见下。

## 分章功能表

**第1章《开市》（钩子段：立世界立冤屈立钩）**
- 入戏：县吏上门索月例孝敬，武大郎不跪不递钱，反把「市集五条店规」钉在摊前——价值转变：权力（看客从看笑话变看新鲜）
- 爽1：店规审判首案——泼皮白吃，按规赔炊饼三十笼，当众执行（切片梗点：店堂即公堂）
- 爽2：说曹操曹操到的结构化首秀：泼皮的兄弟赶来寻仇，撞见武大早备好的「证词链」
- 爽3：望梅止渴式限量预售，日炊饼三百笼改「辰时五十笼」，市集口碑反转
- F1 埋：收拾旧灶台，砖缝里掉出半枚按了指印的空白保书
- B线：武松第一封家书到，「安分」二字被红线圈过
- 章末钩（后果型）：县吏笑纳了同行东家递来的一只锦盒——镜头只看到盒盖上的炊饼印花

**第2章《断粮》（蓄力段：压抑蓄力 + 信息差埋设）**
- 入戏：同行同盟断面粉供，三家粮行同时毁约——价值转变：安全（供给命脉握在别人手里）
- 爽1：分化同盟——当众揭出同盟里谁在偷偷囤粮抬价，弱者倒戈（切片梗点：粮行对账名场面）
- 爽2：军粮改良方：三搭面醒面法 + 行军灶控火，粗面做炊饼反成新招牌（代价可见：掌柜连续两夜守灶、头痛欲裂——穿越代价出场）
- 爽3：以战养战：把同盟违约的毁约金按店规折成「市集信誉银」，反向给粮行定价
- F2 埋：同行东家翻出一只旧木匣，里面是武大郎按指印的保书原件（与 F1 呼应，读者知角色不知）
- B线：第二封家书，字迹变急：「近日县中多事，勿开罪胥吏」
- 章末钩（状态改变型）：县吏带着「私抬粮价、扰乱市集」的拘票上门——告他的人画押名字，是武大郎自己

**第3章《都头》（引爆段：危机选择 + 身份半揭）**
- 入戏：武松提前归家，跨门槛先按刀——他看到的不是哥哥受难，是哥哥「私设公堂、强买粮行」
- 对峙：武力试探 + 言语交锋，曹操以军阵答都头的拳，以账本答都头的问（英雄识英雄的错位版：武松疑的不是哥哥变了，是哥哥背后的「高人」）
- 爽1：保书半揭——拘票上的画押与 F1 的半枚保书指纹对上：有人冒武大郎之名构陷，且只有捏着保书的人做得到（切片梗点：指纹对账）
- 爽2：御状倒打：店规账目 + 毁约文契整链呈给武松，构陷路径反推至同行东家
- 爽3：中点半揭（全弧第5集位）：锦盒炊饼印花 → 东家是官眷出身，供养链浮出水面（改写故事模型：对手从「市集无赖」升级为「官商同盟」）
- B线：武松把刀放在店规匾下——「你的规矩，我替你看着」（兄弟轴从怀疑转结盟）
- 章末钩（情绪型）：曹操望着兄弟背影出门查案，头痛又发作——「这一次，孤的江山只有一间铺面。」

## 卡点体检

每章末答「观众为什么必须看下一集」：第1章——锦盒是谁的、保书是什么；第2章——冒名画押怎么破、武松信不信；第3章——官商同盟怎么打、头痛的代价是什么。均答得上来，无信息空钩。

## 场景复用表（3 景硬约束）

| 场景 | 承担章 | 复用节拍 |
|---|---|---|
| 炊饼铺面 | 1/2/3 | 店规审判、对账、兄弟对峙（当众戏的「众」= 街市群演） |
| 县市集 | 1/2 | 预售、断粮、同盟倒戈 |
| 县衙前 | 3 | 拘票、呈账、御状倒打 |
