# template-推演 · 亮点 preset

编剧推演引擎（点点点剧情推演）的官方演示项目。打开工作台门面 →「推演模式」，或在地址栏直接访问
`http://127.0.0.1:8431/deduce?project=template-推演` 即可开始。

## 玩法

- 引擎每拍给出 **4 个候选反应**（叙事功能四象限：推进 / 回避 / 意外 / 自由）并按四维打分
  （人设一致性 / 剧情推动力 / OOC 风险 / 情绪连贯性），按综合分排序。
- **你只负责点选**。两条路分数接近时引擎会开口问方向（追问的表态会喂回后续推演）。
- 都不对可以自己写；走错了回退上一拍；推完点「收尾成稿」把拍序列串成场景正文（纯正文）。

## 文件

本模板随包出厂只带三件：`推演/script.json`（剧本：场景前提 / 角色卡 / 开场刺激 / 目标拍数）、本 README、`内部/mock-llm.py`（配额窗口外的链路验证）。

推起来才生成的运行件落在**工作区副本**里（模板本体只读，第一次写操作会把整目录复制进 `projects/`）：

- `推演/scene.json` —— 推演状态（引擎落盘，每拍即写）。
- `推演/clickstream.jsonl` —— 你的每次点击留档（选择、回退、自写、追问表态），后续校准用。
- `推演/runs/` —— 每次「重置」归档的旧局。

照 `script.json` 的格式换一部自己的戏即可开新推演；想要一份干净的模板副本，在门面「设置 · 扩展包」里点复制（或直接改项目名新建）。

## 口径

分数是排序建议，不是闸：采纳与否永远由你决定。本模板场景为原创演示内容，与其他项目无人物/地名关联。
