# K1+K2 落地：任务包背景卡 + 派发头生成器（不干扰主线程）

## 目标

subagent 派发从「宿主手写路径清单」切换为「任务包直出规范派发头」：K1 给每个任务包组装确定性项目背景卡；K2 把任务包渲染成可直接复制给 Agent 工具的 spawn 文本（含交卷四要素复述要求）。验收：派发头包含背景卡四要素且测试全绿；`flow_next` 不带新 flag 时输出与现状完全一致（主线程 S3 在跑，零感知）。
