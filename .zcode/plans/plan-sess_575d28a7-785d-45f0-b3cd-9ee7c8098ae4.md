# M1 内核落地计划（miniflow harness · TypeScript）

## 0. 目标与验收口径

在 `core/` 实现七动词内核 + 三张脸（CLI / MCP / HTTP）。验收：**本 agent 通过 CLI 动词，在全新测试项目 `p-e2e-001` 上零手工文件操作跑通 topic-selection 首阶段链路**（src→market→tropes→combo→zeitgeist→benchmark→analysis→gate-r1），含三种关键语义：门挂起→pass 推进、send-back 打回级联失效、进程终止后 resume 恢复不重做已竟之工。

## 1. 设计决策（基于两份探查报告）

**A. 从 v3 照搬的语义**（已知文件级出处，实现时对照）：
1. 快照自带计划+策略+gate+params，**恢复不读图**（两次启动间改图不影响在跑 run）；
2. 每任务边界原子写（tmp+rename）+ 落盘前 schema 复验；
3. 计划编译：拓扑排序 + 环防御报错 + 门任务不聚合；
4. gateToken 三重校验（projectId:runId:gateNodeId + round，旧轮次迟到裁决拒绝）；
5. 裁决三去向：pass（门 done 继续）/ send-back（回滚到阶段入口+级联失效，round 只增不清）/ reject（run failed）；
6. journal.jsonl 事件与快照字段同名同义，坏行容错读；
7. 终态跳过；running/queued 恢复即重跑（宁重跑不留半成品）；
8. 上游未变跳过（v4 用 sha1 指纹，snapshot.py 模型；门永不跳过）。

**B. v4 flow@1 kind 分发表**：`novel-txt`=源步（读文件入注册表）；`core`=spawn python minitool（M1 内建 kb_load + 完整性断言；未实现 minitool 返回类型化 MINITOOL_MISSING）；`agent`=产出任务包（flow_next 返回）；`gate`=挂起等人（幂等二次挂起）；`srd`=人工终点。

**C. when 谓词化**（cond.ts）：识别 `key=value` 形态，key ∈ flow.inputs 键（值取 run-state.inputs，缺省取 default）；"R1 根因=X" 类映射到 lastRejectReason 上下文键；无法识别 → 边不活跃 + journal warn（保守）；`bind.gate` 布尔输入在计划期裁剪对应门后路径。替代现 workflow.html 的硬编码求值。

**D. 契约修订 v1.0.1**：run-state.schema.json 增补事实契约字段（可视化页面在用）：顶层 `comments`/`inputs`/可选 `notes[]`（读侧转 journal 种子）；节点级 `verdict`（pass/pass-with-conditions/send-back）、`rootCauseStage`、`stale`；gate.verdict 枚举扩为 awaiting/pass/pass-with-conditions/send-back/reject。

**E. 技术栈**：TS（ESM）+ vitest；运行时依赖仅 ajv（直接装载 contracts/*.schema.json 为唯一标准）、@modelcontextprotocol/sdk、fastify + @fastify/cors。无状态机库、无 ORM。单写者纪律：lockdir 尽力锁（自写，无依赖）。

## 3. HTTP API（冻结 v1，全部 CORS 开放，默认端口 8421）

GET `/api/projects`（列表+焦点+pending 数）｜GET `/api/projects/:id/state`｜GET `.../graph`（flow.json：画布消费 nodes/edges/stages/inputs/outputs）｜GET `.../artifacts?node=`｜GET `.../artifacts/content?path=`（文本产物全文）｜GET `.../journal?since=&limit=`｜GET `.../snapshots/:node`｜GET `.../workbench-payload`（旧页面 DATA 同构 {flow,files,runstate,snapshots,project}，渐迁桥）｜POST `.../gate` {nodeId,round,verdict,comment}｜POST `.../rerun` {nodeId,dryRun}。OpenAPI 文件 + `/api/openapi.json` 双暴露。
