# 梗密度与发散性约束

**命题：选题阶段是全流程的网感输入源。** 选题产出的梗与素材要喂给后续所有阶段（结构/方案/剧本/传播切片）；梗的传播度和密度不足，后续每一层都会"无趣"——这不是文案问题，是资源储量问题。

## 一、S1 产出硬指标

| 指标 | 要求 |
| --- | --- |
| **网络热梗素材表** | S1 梗卡必须附带 ≥10 条与题材相关的**现存高传播梗**（每条：梗名/来源与传播度评级/可挂接的场景示例） |
| **发散性** | 每个主梗/新变体须可拆出 ≥3 个跨场景可复用的梗用法（对话梗/场面梗/切片梗）——只在一个场景成立的梗不算储量 |
| **密度自查** | 前三章每集至少 1 处可独立切片传播的"梗点"（观众能截出来转发的东西） |

## 二、梗词典数据源（纳入数据库的输入源清单）

| 源 | 类型 | 用途 |
| --- | --- | --- |
| 小鸡词典（含镜像存档） | 梗词典 | 梗的出处、演变、用法 |
| 梗百科 / 萌娘百科 | 百科类 | 梗的条目化解释与传播链 |
| B 站热梗榜 / 抖音话题榜 | 平台热榜 | 当期传播度实测 |
| 知乎"网络流行语"相关高赞 | 语义讨论 | 梗的语义漂移与代际差异 |
| 微博热搜 / 百度指数 | 传播度实测 | 评级数据源 |

接入方式：`meme_harvest` minitool（待实现，规格：抓取/清洗/去重/传播度评级 → 产出 `梗素材表` 增量并入 KB）；实现前由调研步人工按上表整理，**梗素材表仍为 S1 必交付**。

## 三、与既有约束的关系

- 梗密度约束**不替代** C10 设定约束（`kb/market/setting-rules`）：梗要密度，设定要低代入成本，两条红线并行。
- 题材选择本身受梗密度约束**反向影响**：同等条件下，优先选**梗储量高的领域**（如国球/职场/校园——全民梗库富矿），放弃梗荒领域（例：无公共记忆的架空科幻）。
