## 二、热度标尺（判定"多热算热"）

有热度样本 6809 部：中位数 0.6 万（长尾沉底）、P75 = 19000 万、P90 = 35000 万、顶点 150000 万。

- 平均热度 ≥ 2 万万的题材 = **强热度带**；≥1.3 万万 = 主流带；低于全库均值 = 拖后腿带。
- **判定纪律**：说一个题材"热"，必须给到 n（样本数）+ 平均热度，单部爆点不算带。

## 三、题材×热度矩阵要点（CN，n≥100）

强热度带（样本充足且平均热度高）：**打脸**（536 部 / 均 2.27 亿万级）、**逆袭**（1042 / 2.1 亿万级）、**大女主**（1138 / 2.0 亿万级）、**商战**（849 / 1.9 亿万级）、**都市**（1478 / 1.8 亿万级）、**打脸虐渣**（1031 / 1.8 亿万级）。

结构性观察：

1. **打脸是横切引擎不是题材**：它以超族形态（1510 部命中梗族判定）附着在科举/商战/宅斗/流放等各类载体上——选题材时打脸按"必备引擎"计，不按"题材"计。
2. **红海有效 vs 过饱和**（梗族口径，见 `kb/trope/*`）：打脸虐渣、重生复仇 = 红海·有效（量大但热度仍高于均值，进就要带新变体）；马甲掉马、NA 豪门 = 红海·过饱和（热度已被拉到均值下，须谨慎）。
3. **上升期蓝海信号**：流放种田（92 部 / 均 2.26 亿万级）、神豪暴富（380 部）、追妻火葬场——供给尚未追上热度，主推窗口。
4. **NA 出海**：狼人命定、奇幻生物两族处于退潮期（热度均值远低于全库），NA 现在做"阶层打脸 / 灾难动作 / 极限救援"这类硬核动作向（Top 热度全在此带）。
5. **熟龄/银发**：62-65 亿万级热度样本虽少（n=1-2）但单价极高——会话实证方向（熟龄复仇）与市场信号一致，属"样本少但强"的蓝海观察位。

## 四、竞品口径

- 竞品对标直接引用 `kb/benchmark/*` 生成的对标件（热度 + 评级 + 梗族标签齐全），分析报告第三节不再空口描述。
- 策划案兼容性：市场通行的策划案格式是**八段式**（剧名/频类/题材/一句话卖点/共情点/爽点内核/剧情主线/创新亮点+对标）——选题方案 v2 的策划案页按此格式产出，保证与市场同构可比（见 `flows/topic-selection/OUTPUT-FORMAT.md`）。
