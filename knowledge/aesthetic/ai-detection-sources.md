# AI 味检测口径卡（本地打分 × 朱雀对照 · 两级门）

> 定位：外部检测器是**软信号**。检测值方差大（同作品不同章节 0%/44%/87% 均有公开实测），
> 不做 block 裁决；硬约束始终是本仓库 `AE-PROSE-*` 文本层断言（配额层 + 八维画像）。

## 两级门（50 万 token/月 额度纪律）

| 级 | 时机 | 工具 | 成本 |
| --- | --- | --- | --- |
| L1 本地打分 | **每章完成即跑** | `tools/prose-scan.py --json`（配额层 + 八维画像 → AI味指数 0-100） | 零 |
| L2 朱雀对照 | **仅终稿/交付门，一次** | `tools/zhuque-check.py --compare <scan.json>`（官方 API） | ~千字≈1k token |

L2 的目的不是重复打分，是**校准 L1**：对照表（本地指数 vs 朱雀 softmax/ratio）落收据，
积累数份后即可信任 L1 单独站门，L2 降为抽检。

## 检测源矩阵（2026-09 调研）

| 源 | 口径 | 用途 |
| --- | --- | --- |
| 腾讯朱雀（官方 API） | 文风统计分类，创作向主口径；网页版匿名 5 次/设备，API 走 EdgeOne Key | L2 对照 oracle |
| 知网 AIGC / 万方文察 / 维普 / 大雅 | 学术论文向，偏宽（易漏检） | 反向对照，防口径过拟合 |
| PaperPass / 茅茅虫 等 | 偏严（易误杀，老舍原作误判案例） | 不建议做门 |
| 番茄平台 | ≥30% 人工加工 + AI 标注；检测看语义范式/桥段相似度/叙事结构/对话模板 | 交付硬指标（人工比+标注），非文本相似度 |
| 起点 | AI 占比 >10% 即下榜；编辑初审 AI 识别引擎 | 同上 |
| GB 45438-2025 + 四部门标识办法 | 强制国标：显式标识 + 元数据隐式标识（2025-09-01 施行） | **合规红线**，与质量无关 |

## 纪律

1. 检测数值只进 `warn` / 摘要标注，**不许做成 block 硬断言**（不引外部检测器当机器校验器）。
2. 朱雀调用前先跑 L1：L1 指数 ≥40 时先本地改，改完再送 L2——别拿 token 试错。
3. 每次调用落收据（`内部/收据/朱雀检测-*.json`）；配额台账 `.zhuque-usage.json`（80% 预警、100% 停）。
4. 标识合规：AI 参与内容对外发布必须带显式/隐式标识（GB 45438-2025），这与去 AI 味是两件事。
