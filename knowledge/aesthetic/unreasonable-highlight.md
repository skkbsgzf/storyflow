# 不合理亮点标准

**定义**：**不合理亮点 = 性格允许、情绪为真，但"委员会不会通过"的选择。** 它在提案时显得冒险甚至错误，回看时却是全剧最被记住的节点。

**靶子**："太合理"的剧有一个共同病理——每个关键节点都取了**唯一安全解**（编剧/模型/多轮修订不断磨掉风险，直到人人都能猜到下一步）。本标准是磨平的逆过程：把值得冒的险找回来。

## 一、死点定位法（哪里被磨平了）

对每个关键节点做两问：

1. **唯一解测试**：这个节点是否只有一个"不挨骂"的选择？列出 2-3 个被放弃的替代项——如果替代项都更刺激，此处是死点。
2. **后悔测试**：如果主角/反派做出"性格允许但剧情不鼓励"的选择，后果是更无聊还是更锋利？"更无聊" = 该选择真必要（放过）；"更锋利但有风险" = 磨平点（挖）。

## 二、三源生成法（不合理从哪来）

| 源 | 机制 | 依据 |
| --- | --- | --- |
| **未兑现的矛盾** | 人设深处立过的"维"（性格矛盾）还没被花掉——让矛盾在最贵的时刻爆 | character 维度"维=矛盾"；矛盾兑现权重（redline-scoring） |
| **类型契约的破坏点** | 违反类型的**表层**惯例，但兑现类型的**深层**承诺（观众要的不是惯例是情绪） | 韩法大师班："类型 = 对观众的承诺"——破坏承诺的写法 vs 兑现承诺的反惯例 |
| **情绪逻辑 > 情节逻辑** | 情节上不划算、情绪上必然的选择（人在情绪顶点不做最优解） | "写情绪不写哭"一脉；情绪真实性先于策略最优 |

**示例**（供校准，不是模板）：

- *calm 档*：女主拿到足以致命的证据，先不动手，反而请反派吃了顿饭。情节上错失时机（不合理），人物真相上成立——她要的不是赢，是对方**知道**。回看：前文她已两次"只看表不说话"。
- *hot 档*：反派在最强时当众给主角递刀。看似降智，实为傲慢演到满——"你赢了也没用"，为三集后的打脸蓄力（反派话更满条款的极端化，打脸更响）。
- *通用*：关键抉择交给最不该做决定的人（小人物/敌对方）——代价与不可逆性瞬间拉满（代价梯一次动两个维度）。

## 三、四道合格过滤（不合理 ≠ 乱来）

每个提案必须全过，任一不过即弃：

1. **回看成立**：≥2 处可暗埋的铺垫位置（reversal 维度 AE-REV-SETUP 同源——不合理必须经得起二刷）。
2. **代价相称**：选择付出看得见的代价，且与冲突规模匹配（ending 维度联动；代价归零的不合理 = 廉价噱头）。
3. **主线同源**：服务于核心冲突或主题命题，不是支线猎奇（hook 维度"主线同源"条款的镜像）。
4. **人物真相可回收**：压力下这个选择揭示的人物真相，在后续有兑现位（character 维度"他选故他在"）。

## 四、禁止项（block 级）

- 纯随机反转（零铺垫、与人物无关）——违反 reversal 维度
- 崩人设无回收（为惊而惊，人物真相断裂）——违反 character 维度
- 触碰合规红线的"不合理"（platform 维度 block 项永不豁免——合同优先于审美，也优先于红方）
- 违反路线契约的混档提案（hot 档提案不得要求潜台词，calm 档提案不得要求当众撕——style-routes 互斥表）

## 五、存量要求与路线差异

- 全稿不合理亮点**存量 ≥1**（AE-RED-INVENTORY）；存量 = 0 即平庸实锤，红方必判 challenge。
- 每个提案按 `unreasonable-highlight` 条目格式输出：`{ 节点, 现选择, 为何安全, 提案, 为何更好, 回看机制(铺垫位), 代价, 档位适配 }`。
- **calm 档**的不合理 = 克制中的反常（爆点因稀缺而贵，不合理因罕见而贵——每集 ≤1 的额度优先花在不合理亮点上）。
- **hot 档**的不合理 = 爽点的新鲜度（同样的打脸，换一个"不该在这里打"的位置）。
- 合理与不合理的配比本身就是审美：全稿处处不合理 = 另一种可预测（故意唱反调成套路）——红方对自身的这一失效同样负责（哨兵钝化自检，redline-scoring §五）。
