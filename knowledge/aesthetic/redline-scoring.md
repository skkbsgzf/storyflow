# 红方评分标准（对抗式打分）

**标尺**：蓝方（生产技能 + 审美总编 + 交付监理）回答"达没达标"；红方打分官回答"**是不是太安全了**"。一部所有节点都合理的剧，是一部可预测的剧——可预测是商业剧的第一死因（会话实证判词："缺部分新意……主旋律选题 + 新意诠释 + 扎实基本功"，新意即本标准的靶心）。

红方与蓝方的关系是**对抗**而非复核：红方不重复蓝方的 49 条断言扫描（那是 minitool 的活），只攻蓝方结构性看不见的盲区——**安全化磨平**。

## 一、六个红方维度

| 维度 | 问题 | 测法 |
| --- | --- | --- |
| **可预测性** | 老油条观众能否步步猜中 | 冷读者测试（§三） |
| **安全系数** | 有多少"委员会选择"——存在的原因只是没人会反对 | 逐关键节点问：换个有风险的选项，是否更刺激？ |
| **惊喜存量** | 结构必需之外的意外之喜有几处 | 对照爆点分布图，区分"结构required"与"意外" |
| **代价真实** | 选择是否付出看得见的代价 | ending 维度"代价相称"的红方视角：代价归零处即编剧怯战处 |
| **钩子衰减** | 后程是否吃老本 | 前 3 集每拍冒险，第 6 集起是否只剩执行 |
| **矛盾兑现** | 人设深处的"维"（性格矛盾）是否被兑现过 | character 维度"维=矛盾"的红方审计：只立不兑 = 摆设 |

## 二、路线权重与分数带

| 维度 | hot 权重 | calm 权重 |
| --- | --- | --- |
| 可预测性 | 25 | 15 |
| 安全系数 | 20 | 15 |
| 惊喜存量 | 20 | 10 |
| 代价真实 | 10 | 25 |
| 钩子衰减 | 15 | 10 |
| 矛盾兑现 | 10 | 25 |

分数带（0-100）：

| 带 | 红方裁决 | 门行为 |
| --- | --- | --- |
| 85-100 | `pass`（过线） | 意见书归档；连续两次全过触发**哨兵钝化自检**（§五） |
| 70-84 | `pass`（附注意事项） | 意见书归档，注意事项进 journal 供下轮参考 |
| 55-69 | `challenge`（挑战） | 强制回应循环：蓝方须对每条挑战**采纳 / 改良 / 书面反驳**三选一，对抗记录附验收门 |
| <55 | `veto`（否决建议） | 验收门建议驳回重写；裁决权仍在人（`allow_agent_verdict` 纪律不变） |

## 三、冷读者测试（可预测性测法）

1. 从大纲/分集结构抽取 K 个关键节点（大卡点 / 反转 / 关键抉择，K ≥ 5）。
2. 隐去节点内容，只给冷读者（宿主的**另一个无污染实例**，未读正文）前情与人物动机。
3. 让冷读者猜每个节点的走向；**猜中率 ≥60% 的节点标记为"可预测死点"**。
4. 每个死点必须配一个不合理亮点提案（见 `kb/aesthetic/unreasonable-highlight`）——只报问题不给替代方案 = 红方失职。

## 四、意见书（红方唯一合法输出物）

```text
红方意见书（.md + .json）
├─ 总分 + 六维分项（按路线权重）
├─ 裁决：pass / challenge / veto
├─ 反对意见[]：{ 锚点, 主张, kb_ref（引用知识条目 ID 作依据）, 级别 }
├─ 可预测死点[]：{ 节点, 冷读者猜中率, 提案 → unreasonable-highlight 条目格式 }
└─ 蓝方回应[]：（回应循环后回填：采纳 / 改良 / 反驳 + 理由）
```

纪律：**每条意见必须挂 kb_ref**（引用 `kb/...` 条目作依据）——红方是标准驱动的对抗，不是口味点评；无依据的"我觉得不够刺激"无效。

## 五、哨兵钝化自检

红方的失败模式是被蓝方同化（连续 pass = 社会化钝化）。触发条件与处置：

- 连续 2 次全过线 → 意见书强制附加"钝化自检"：重新以最严维度复扫一遍，明确写出"这次我放过了什么"。
- 连续 3 次全过线 → 门行为升级：抽 1 个高分节点强制做冷读者测试复核。
- 红方从不修改正文（那是蓝方的活）；红方的武器只有评分、反对意见和提案。
