# AI 痕迹标准

**标尺**：AI 味是**叙事结构级**的，不是词句级的。实证（sepia 引用 61608 篇语料研究）：分类器只看叙事结构、不看用词，识别准确率 93.2%；人工编辑改表层风格后仅从 95.5% 降到 93.9%——**词句层打磨对结构级检测几乎无效**。降 AI 率必须改结构，这决定了本维度的全部判定位置。

> 与 `kb/aesthetic/naturalness-zh`（24 类词句层清单）分工：那边管"词句模板腔"，这边管"结构机味"。过朱雀类检测器（星月写作路线的完整方法论）= 两层都过，但本维度是瓶颈层。

## 判定条款

1. **【major】手法配额（减法纪律）**：单篇只挑**三五种**叙事手法刻意使用，其余留白。手法堆满 = 均匀的"太正确"，正是结构级机味的来源——**减规则治假，加规则治崩**（前者本维度管，后者归 continuity 层管）。
2. **【major】结构指纹自查**：逐项扫结构级机味——
   - 章节功能序列过于规律（每章都是"冲突→小胜→钩子"的等差节奏）
   - 场景切换永远用同一种过渡（时间/地点/视角的转换模式单一）
   - 情绪曲线平滑无毛刺（真实作品有意外的情绪跳动与"浪费"段落）
   - 每段信息密度均匀（人类写作有密有疏，见 `kb/deconstruct/style-learning` 笔墨密度表——密度应随情绪剧烈波动）
   - 对话回合数过于对称（真实对话常一回合内多次交锋或突然终止）
3. **【minor】盲写混合**：修订时允许对关键段落做"脱离上下文盲写再缝合"——结构多样性来源之一（InkOS 的修订位实践）。
4. **【minor】检测器校准**：以朱雀类检测器为**参考信号而非目标函数**——对着检测分优化会走向更隐蔽的模板；目标始终是结构自然度本身。

## 检测器八维画像（v1.1 新增——打磨时力该往哪使）

网文平台 AI 检测 = 多维统计特征异常识别 + 加权评分（对人类样本分布算偏离度，0-100 AI 倾向分）。权重排序：**重复 > 句长 > 词汇 > 模板 > 标点 > 对白 > 情绪 > 语义**。八个维度（ref:developer.volcengine.com/articles/7609936833770127386）：

| 维度 | 指标 | 危险信号 |
| --- | --- | --- |
| 短语重复 | 3-gram 重复率 | 同一三字以上短语复现（「他冷冷地看着」式）——**最高权重** |
| 句长波动 | 句长标准差 | 连续等长句；自然区间约 3.5±2.5 |
| 词汇多样性 | 去停用词 unique/total | ≤0.20 高风险（≥0.55 接近人类） |
| 模板化表达 | 套话命中率 | 见 kb/aesthetic/slop-list §二叙事套话黑名单 |
| 标点节奏 | 标点间隔变异系数 | 过于均匀（自然约 0.45）——隐藏但杀伤力大 |
| 对白比例 | 对白占比 | <5% 或 >65% 两极异常 |
| 情绪/感官词密度 | 密度波动 | 过低像说明书，过高像堆情绪 |
| 语义平滑度 | 相邻句 embedding 相似度 | >0.92 = 衔接过于顺滑，缺「思维断层」 |

短文本（<80 token 或 <5 句）四项降权：句长/标点/情绪/对白——章级检测以整章为单位。**打磨含义**：3-gram 重复与句长抖动优先级最高，先查它们再抠词；与 §判定条款 2 的结构指纹互为表里（统计层/叙事层）。

## 与知识库的闭环

本维度的结构多样性素材来源 = `kb/deconstruct/style-learning` 拆出的真实作品节奏规律（收束四型轮换、笔墨密度波动）。**拆真书 → 提炼节奏变化模式 → 注入结构**，是去机味的正路；同义改写是歧路。
