# 冲突升级标准

**标尺**（韩法口径）：**故事 = 危机加深 × 欲望加强**，两条线必须同时拧紧；只有一条在动 = 冲突空转。

## 一、因果链八节点（wcls 全片因果链，节点必须用"人物选择 + 后果"定义）

1. 主题命题与反命题（写成"某种价值结果，因为人物以某种方式行动"，不写抽象口号）
2. 主角欲望（外在欲望可观察；内在需要早期可不自知，但必须通过行为模式体现）
3. 激励性扰动（打破稳定，使主角原有策略失效）
4. 递进复杂化（**对抗力量学习和适应**；代价、范围或不可逆性逐步增加）
5. 不可回头点（主角的选择关闭便宜退路，不只是外界偶然封路）
6. 危机选择（互不兼容且均有代价的方案中选择）
7. 高潮行动（把危机选择落实为不可撤回的行动，全片最大价值变化）
8. 结局价值与余波（新秩序、损失、仍未消失的代价）

| 缺陷 | 级别 |
| --- | --- |
| 不可回头点不含主角选择（只是外界封路） | major |
| 危机是可两全的选择 | major |
| 对抗力量不随主角行动而调整（反派复读） | major |
| 转折不来自已建立的机制/人物/证据 | block（联动 ending 维度） |

## 二、代价梯（wcls：一次只动一到两个维度）

可用升级维度：时间 / 公开性 / 亲密性 / 依赖 / 知识 / 选择空间 / 道德成本 / 不可逆性 / 对手适应。

- 【major】所有维度同时上升 = 提前耗尽空间，判 major。
- 【minor】持续高强度不回落 = 强度失效（钝化），需要谷段垫场（pacing 维度联动）。

## 三、冲突四层次（麦基/希克斯，按场景组合）

外在（时空物质）→ 社会（制度权力）→ 个人（亲密关系）→ 私密（自我矛盾）。全稿至少横跨三层；只有外在层 = 打架不冲突。

## 四、冲突形态合规（埃格里）

- **rising conflict**：冲突逐步上升为常态；**static conflict**（谁也不动的僵持）超 2 拍判 minor；**jumping conflict**（无过渡的暴跳）判 major——过渡就是戏。
- 对立统一：冲突双方的立场必须各自成立（"有理由的错误选择"）；一边全错一边全对 = 冲突失效，判 major。

## 五、路线差异

- **hot**：冲突外化、当众化（直播间/董事会/婚礼现场），身份碎片当众撕；反派话越满，打脸越响。
- **calm**：暴力降级为权力（董事会席位/债权函/一条录音）；最狠的台词在最后一句，前面全是铺垫。
