# 人物审美标准

**标尺**：人物真相 = 压力之下的选择（麦基："他选故他在"）；压力越大，揭示越深。人物立不住，冲突和对白的一切毛病都是它的症状。

## 一、三维齐备（埃格里）

- 生理 / 社会 / 心理 三维，作者须知（不必全写进剧本），**经由行动传达**。"乏味、脸谱化、千人一面"的评语都源于缺维度。
- 【major】**为什么一定是她**：主角的人设必须能回答"为什么这件事非她不可"——排除其他人的可能性（辩证证明）。人设"不够爽"的病根多在此（会话实例：拍卖师身份不含不可替代性）。

## 二、人物塑造 vs 人物真相（麦基）

- **人物塑造** = 可观察素质总和；**人物真相** = 压力下的选择。
- 【major】主要人物内心绝不能和外表一样（看似如此，其实并非如此）——压力节点必须出现"揭示性选择"。

## 三、维 = 矛盾（麦基）

- 【major】深维来自矛盾：性格内矛盾（负疚沉重的野心）或塑造与深层性格的反差（魅力四射的小偷）。须连贯——好人踢一次猫不算维。
- 【major】**主角必须最多维**（太阳系设计）：主人公是太阳，配角行星、小角色卫星；配角存在完全为刻画主角的维。主角扁平而配角抢戏 = 结构性失衡。
- 反面清单：怪癖清单不等于维（金融+霹雳舞+空手道+萨克斯 = 平板）。

## 四、对手要强（陆军 + 递进复杂化联动）

- 【major】"给对手一把刀"：对手必须有独立的欲望、方法与学习适应能力（对抗力量会根据主角上一次行动调整——scene-value 维度联动检查）。
- 反派降智仅 hot 档限额合法（快餐法则：反派的智商为爽感服务），但主反派在关键卡的强度不得降智——否则打脸不响。
- "最强的对手是自己"：私密冲突层（不愿面对的欲望/恐惧）至少在主角身上布一条。

## 五、人物专属语言（wcls 对白引擎联动）

- 【minor→盖名测试】为主要人物记录：词域句长、身份对语言的影响、压力下语言的变化方式（变短/变密/变正式/失控）。**遮住人物名，仍应能根据策略、知识和语言选择辨认说话者。**不靠口头禅区分人物。
- 【major】动机纪律：不把动机固着于具体原因（虐待儿童片段式解释 = 陈词滥调）；自我解释放口袋里（里克："我再也不为任何人出头"——"哦，还没到时候"）。

## 六、hot / calm 档位差异

| 档位 | 人物表达 |
| --- | --- |
| hot | 立场写在脸上（好人笑起来暖，坏人笑起来假）；禁止观众推理 |
| calm | 人物真相靠克制选择揭示（她看表）；反派体面地崩塌（一层层被剥掉），不是当场被打晕 |
