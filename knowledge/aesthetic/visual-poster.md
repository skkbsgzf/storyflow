# 名场面可视化标准

**标尺**（审美总编第三条）：大纲与前三集里每个关键爆点，必须能画成一张**海报级分镜**——画不出来的爆点 = 不存在，删掉换一个能画的。短剧/漫剧是视觉媒介，文字的强度必须兑换成画面的强度。

## 判定条款

1. **【major】海报五要素**：关键爆点可回答——谁、在哪、对谁、做了什么、画面记忆点是什么。五问有一答不出 → 判 major，改写或换爆点。
2. **【block】禁空镜禁不可拍摄**：心理描写、文学抒情、无画面信息是禁手（剧本是生产工具：导演分镜/演员表演/剪辑时间轴全靠它）。
3. **【minor】爆点视觉锚**：爆点拍在"画面"栏直接写情绪强化物（慢镜、定格、特写砸桌、酒杯碎裂、红灯熄灭）——给后期与 AI 生图的明确锚点。缺失判 minor。
4. **【major】物件母题**（calm 档为硬标准，hot 档建议）：≥2 个贯穿物件（旧婚戒/怀表/剪报本），每个爆点绑定一个物件——可复现、可特写、可当海报；伏笔回收与物件复现联动。

## 竖屏形态适配

- 【minor】人物众多的全景戏、依赖横屏构图的场景 → 改为近景可拍的表达（竖屏画幅纪律）。
- 名场面优先近景强表情 / 手部特写 / 空间纵深单点（对峙线），不依赖群像调度。

## 与爆点分布的联动

全剧爆点分布图（审美总编第四条）逐段标注爆点位置时，每个标注点必须同时挂一个可视化锚（画面记忆点短语）；两个大卡点之间的中型爽点至少一半可海报化。沙漠段判定的同时检查可视化密度——纯对话推进段若无视觉锚，双判 pacing + visual。
