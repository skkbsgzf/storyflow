# 风格路线参数表

路线 = 路线（激进/平缓）× 风格（快餐/深沉）的组合。**两档互斥**——一条 flow 产出两版时，是两个并行子图各挂一档，禁止在同稿混档（AE-ROUTE-EXCLUSIVE）。

## hot（爽版：激进 × 快餐）

对标：《我在八零年代当后妈》《无双》的爆点密度口径。目标"更爽、更脑残"——零理解成本，三秒一下，情绪直接灌喉。

| 参数 | 值 |
| --- | --- |
| 爆点密度 | 每集爽点 ≥3；每 3 拍一个小刺激 |
| 回击时差 | 受辱→回击最多隔 2 拍（绝不写"她忍了下来"；忍也只能忍到集尾连本带利收） |
| 身份揭示 | 马甲当众层层撕，必配群演反应拍；撕前反派话须说满 |
| 潜台词豁免 | **豁免**（禁潜台词、禁留白、禁推理；立场写在脸上） |
| 金句复读 | 口癖每集 ≥1 次；重要金句 3 集内变奏重复 3 次 |
| 反派智商 | 可降智为爽感服务；关键卡不降 |
| 台词 | 短、狠、口语化，一句一个信息点 |
| 视觉 | 爆点拍必写情绪强化物（慢镜/定格/特写砸桌） |
| 底线 | 拍号、卡点、口癖、3 秒钩子四硬规则不豁免 |

## calm（合理版：平缓 × 深沉）

对标：《黑暗荣耀》浓度配比。写"爽得贵"，不写"爽得 cheap"。

| 参数 | 值 |
| --- | --- |
| 浓度配比 | 9:1（90% 蓄力 + 10% 引爆） |
| 爆点密度 | 每集 ≤1，且为前 ≥20 拍铺垫的兑现 |
| 情绪表达 | 克制（不哭喊；愤怒 = 更轻的声音、更慢的动作；台词不超两句，说完就走） |
| 复仇形态 | 执行遗嘱（计划表感）；伏笔回收率 >60% |
| 物件母题 | ≥2 个贯穿物件，爆点绑定物件（硬标准） |
| 暴力 | 降级为权力（席位/债权函/录音）；反派体面地塌 |
| 台词 | 金句留白不解释；每集感叹号 ≤2；最狠的在最后一句；禁网络烂梗 |
| 底线 | 第一拍依然是钩子（深沉 ≠ 慢开场） |

## 路线声明协议

flow@1 的 input 显式声明路线（`route: hot | calm | dual`）；`dual` 时 outputs 必须双版本（合理版 + 爽版）+ 基线对照件（无监管版，用于验证监管增益——会话 A/B 实证纪律）。每版交付物文末附本档自检清单（按上表逐项打勾）。
