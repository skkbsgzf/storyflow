# 平台适配与合规标准

**标尺**：平台运营口径——只管影响流量与合规的事。本维度的特殊纪律：**合规项永不降档、宁可错报不可漏报**（总纲唯一例外条款），但每条必须给平台规则依据，不许凭感觉。

## 一、合规红线（全部 block，不错报不漏报）

1. 露骨描写
2. 真实人名 / 真实品牌
3. 医疗、金融绝对化承诺
4. 未成年人相关敏感情节
5. 题材禁区（以约束移交单为准——oversight 维度联动，合同优先于审美）

## 二、卡点运营标准

- 【major】付费卡点位置与强度：第 8-12 集首卡区间，标【付费卡点】，悬念强度到顶点（误会顶点/身份将揭）。
- 【major】每集末"卡点体检"：答不出"观众为什么必须看下一集" = 失败卡点（修法见 pacing 维度：信息型/情绪型）。
- 【minor】卡点频率：约每 8-12 拍需要一个强钩；通篇无明确卡点判 major。

## 三、竖屏形态适配

- 【minor】全景群戏、横屏构图依赖 → 改近景可拍表达（visual 维度联动）。
- 短剧纪律（wcls 竖屏短剧节）：尽快给本集即时目标；每场保留一个清晰权力变化；身份/资源/证据/关系在画面中可立即识别；避免每集同一种打脸/偷听/撞见；长线反转仍需提前布置可回忆证据。

## 四、信息密度与平台节奏

- 前 3 秒钩子（hook 维度 block 级联动）。
- 单集 90-120 秒 / 600-900 字 / 拍号连续（pacing 维度 AE-BEAT-FORMAT 联动）。
- 开局结构二选一：慢蓄力型 / 快反击型（pacing 维度），与路线档位匹配（hot ↔ 快反击，calm ↔ 慢蓄力，可混合但须显式声明）。
