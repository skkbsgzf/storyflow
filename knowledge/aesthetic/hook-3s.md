# 开场钩子标准

**标尺**：第一拍必须让观众 3 秒内产生生理反应（倒吸凉气 / 坐直 / 骂出声）。第一拍是钩子，任何路线下都不例外——深沉档"钩得高级"，不是"钩得晚"（v3 硬约束）。

## 判定条款

1. **【block】钩子事件在场**：前 3 秒（或首 100 字）出现四型钩子之一的具体**事件**。氛围铺垫、世界观说明、人物自介 = 缺钩，判 block。
2. **【minor】十五字可复述**：钩子在 15 字内可复述。超出判 minor。
3. **【major】主线同源**：钩子必须与核心冲突同源。钩子是支线悬念判 major——**开场钩必须长成长主线**。
4. **【block】零先验依赖**：二刷视角检验——钩子成立是否依赖观众不存在的先验知识。依赖即 block。
5. **生理反应测试**（总纲四步流程之盲读项）：把第一拍画面念给没看过背景的人——问"然后呢"过；问"这是什么意思"重写。

## 四型钩子句式模板（每型 3 例，供改写时直接套用）

- **悬念**：「他/她刚 X，就 Y 了」；「没有人知道，X 的真正原因是 Y」；「这条 X，是 Y 留下的最后一件东西」。
- **反常**：「这里是 X，但正在进行 Y」；「所有人都 X，只有他 Y」；「X 做了 Y，表情却是 Z」。
- **危险**：「X 还有 N 秒抵达」；「如果被 X 发现，Y 就完了」；「门开了——进来的是 X」。
- **承诺**：「从今天起，你要 X」；「这本 X，能让你 Y」；「三天后，你会感谢此刻的 X」。

## 路线差异

| 档位 | 钩法 |
| --- | --- |
| hot（爽版） | 危险/反常型优先，情绪直给，第一拍即冲突正面 |
| calm（合理版） | 悬念/反常型优先，第一拍即钩、钩得高级——用反常的**克制**制造不安（"她看表"），不用背景交代 |

## 判分输出协议

对开场拍逐条判 1-4，命中即给模板级建议（"此处宜套用危险型第 2 句式"）；四型全不沾 = block 整集重开。
