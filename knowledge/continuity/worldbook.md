# 世界书体系标准（小说/剧本双变体）

**命题：所有叙事项目共用一套世界书骨架——文件即真相、类型化建档、逐章（集）结算、可检索。** 变体只差「结算单位」（小说=章，剧本=集）与特有卡种（剧本多场景卡/道具卡）。

## 一、目录模板

```
projects/<id>/世界书/
├── index.json        # 唯一 RAG 入口：sections[].entries[]（id/title/tags/links/status/version/updated/file）
├── 纪律.md           # 本项目的更新纪律（按变体生成）
├── 设定/             # 世界规则（list 型：一规则一文件）
├── 人物/             # 一人一卡（list 型；四型：主角/主要配角/次要配角/路人——入场即建档）
├── 势力/             # 一势力一文件
├── 地理/             # 一地一文件（小说）；剧本版=场景/（场景卡，有名场景≤3 硬约束联动）
├── 编年/ 或 分集账/    # 小说=编年（大事记+章账）；剧本=分集账（每集结算）
├── 伏笔/台账.md       # 机器可读：fid/内容/埋点/预定回收/状态 open|paid|retired
└── 底牌/暗线底牌.md    # 作者专用，status: draft，永不入正文
```

**落位硬约束**：卡片与总览一律写**项目根** `世界书/<分类>/<词条>.md`（flow outputs 契约同款路径），禁止跟节点产物同域落（如 `02-编剧/世界书/`）——归纳器 `tools/worldbook_index.py` 只扫项目根 `世界书/`，写进域目录不报错但 graph 永远空（p-e2-01 事故形态，2026-09-28 销账）。

### 小说变体特有

- **编年/章账.md**：逐章结算账（章卡/人物状态变动/世界揭示/交接下一章）——下一章写手只读章账末节（handoff 语义），不重读全书；
- 成长四阶/招式名目等「名目层」入 设定/名目与黑话.md。

### 剧本变体特有

- **场景/**：场景卡（场景号/陈设/出场集数/复用节拍）——联动 `kb/aesthetic/scene-value` 有名场景 ≤3 硬约束；
- **道具/**：道具卡（谁/在哪集/状态）——连续性道具（信物/凶器）必建档；
- **分集账/集账.md**：每集结算（集卡/人物状态变动/伏笔变动/世界揭示/交接下一集），替代章账；
- 与 词汇表.json（own/banned）并行：词汇表管专名安全，世界书管设定真相。

## 二、条目规范

- frontmatter：`id / title / 类型 / tags[] / links[] / status / version / updated`；
- 状态机：`draft（设定中）→ active（已进正文）→ retired（被推翻；不删档留存——设定迭代本身可成为剧情）`；
- 人物卡三段：核心档案（要/怕/卡）→ 关系网 → 当前状态（随结算滚动）+ 变动史（追加）；
- `[[id]]` 交叉链接；文件即真相，索引只做指针——**改文件必须同步 index（status/version）**。

## 三、章（集）回结算五件——「不断更新」的执行点

每章（集）交稿后、下一章派发前，宿主按写手「待登记清单」结算：

| # | 结算件 | 写入处 |
| --- | --- | --- |
| 1 | 章卡/集卡（一句话+梗点+钩型+新名目） | 编年/章账.md 或 分集账/集账.md |
| 2 | 人物状态推进（伤/钱/知情/关系/位置） | 人物/*.md 当前状态+变动史 |
| 3 | 交接（下一章/集写手必知的 3-5 条） | 章账/集账末节 |
| 4 | 伏笔变动（新埋/回收/顺期） | 伏笔/台账.md |
| 5 | 世界揭示（本章确立的新设定事实） | 设定/*.md、编年/大事记.md |

## 四、RAG 规则（写第 N 章/集的开工动作）

1. 读 index.json 按 tags 拉相关词条（写第 47 章只拉 3 个词条，不重读全书）；
2. 读章账/集账**末节**（=上一章 handoff）；
3. 读伏笔台账中 open 且预定回收点临近的条目；
4. 底牌仅暗线节点需要时按节点号取段，禁止整读。

## 五、工具与前端

- 脚手架：`python tools/worldbook.py init <project> [--variant novel|drama]`；校验：`check <project>`；预览：`tree <project>`；
- 前端：flows/graphs.html 的「世界书体系」页签（tools/render-flow.py 生成）——渲染双变体模板、结算纪律与各项目世界书实况。
