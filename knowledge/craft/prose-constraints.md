# 成文约束总纲（六维路由）

**标尺**：约束不进上下文 = 约束不存在。成文者写前只装两样：本卡（路由表）+ 当前正在写的那一维的被路由卡。盖章时按本表逐维过，清零项违规即打回，不进入下一段。

## 规则强度三级

- **清零**（铁律）：叙述层出现即打回，无配额可言；
- **配额**（天花板）：允许存在但封顶，配额是上限不是许可额度；
- **判定**（该改/该保留）：命中后过两问——该保留（承担转折/确有信息/真人声口/可拍摄）、该改（空转/拔高/脱离场景）。

## 段落盖章单（每段六维各一枚，全过才下推）

```
段 #N ｜ 维度戳：台词□ 场景□ 设定□ 人设□ 节奏□ 机味□
任一维不过 = 本段重写；连续两段同一维不过 = 停笔回读该维路由卡。
```

## 分工边界（拒屎上雕花）

- 剧情与场面在**分场卡**锁定（编剧流：分镜/五行卡），成文者无权改情节走向——发现剧情问题回分场卡修订，不在正文里硬拐；
- 文学质量在**成文时内置**（本表六维逐段盖章）；
- polish（novel-deai）只是**收尾薄修**——它救不了烂原文，只负责摘掉漏网的机味。
