# 用户补充 · 文学规则（公用 md，手动追加区）

> 这是**用户手改的公用规则文件**：本仓库成文/交付流水线会装载本卡（成文任务包注入 + prose-scan 机械检查）。
> 直接改这个文件即可，改完即生效（文件即真相）。每条规则建议带「机械判定」说明——写了判定口径的规则会被 prose-scan 自动扫描。

## R1 · 对白引号口径（成文正文）

- 正文对白一律使用 **“……”**（内层嵌套用 ‘……’）。
- **「」直角引号不得进入成文正文**——既不当对白引号，也不当术语强调号；术语需要强调时用“”或改写。
- 机械判定：成文产物（对外交付/章节正文/终稿）中出现 `「…」` 即计一条格式红线。

## R2 · 加粗滥用（对外交付）

- 章节正文/终稿：正文段落内**禁用装饰性加粗**（全篇 ≤1 处，仅限功能性：信件抬头、牌匾原文等）。
- 报告/意见书类对外文档：加粗 ≤2 处/千字，且只用于真正的结论句，不做排版花活。
- 机械判定：统计 `**…**` 出现数，按上述阈值报格式红线。

## R3 · 箭头链（思维链残留）

- 所有对外交付与阅读向文档**禁用推理箭头**（`→` `->` `=>`）——因果与推进必须写成叙事句。
- 过程图/流程表内的符号另议（tables 里的编排符号不算）。
- 机械判定：正文出现箭头符号即计一条格式红线。

### R4 · 中文引号全局口径（称号/题字/术语引用）

- 中文语境的一切引用记号——称号荣誉、题字漆文、文书引文、术语强调，**不限于对白**——一律用 **“……”**（内层嵌套 ‘……’）；**「」『』直角引号不得出现在任何交付产物**（章节正文/剧本/大纲/报告/导出文档/交付页均适用，R1 只管成文正文，本条管到全部产物）。
- 例：搪瓷缸漆字应写作 “防汛模范”，不得写作 「防汛模范」。
- 机械判定：prose-scan format_redlines——对外交付/正文/剧本/交付页（04-交付）类路径出现 `「…」` 即计格式红线（limit 0）；其余产物（大纲/报告等）由评审步人工执行。

### R5 · 换行分段纪律（成文正文）

- 一个角色的一个行为拍结束，或场景/时空/话题切换，**必须另起一段**——段内不并置两个以上的行为拍；宁可段多，不可粘连（粘连=读起来难受，用户口径 2026-09-21）。
- 对白换人或动作换向，同样另起段；单段以「一口气能读完」为准。
- 机械判定：prose-scan `4b 段落地形`——单段 CJK >150 字即报「查行为拍/场景切换是否未换段」（证据行，不占 AI味分；拆不拆由写手/评审按本条裁决）。

### R6 · 主谓宾显化（成文正文，动作段最严）

- 每句施事主语显化：**同一画面里有两个以上在场角色时，禁止裸用「它/他」开启新句**——用点名（狼/小鲸/林寻）或名词短语承担主语。
- 跨段承接禁止主语漂移：段首句的主语必须在本句内可独立判定，不许依赖「上一段主语还是谁」的记忆。
- 谓语链不偷换：一个动作链句里前后动词的施事必须一致，换施事即另起一句（事故句式：「小鲸张开嘴。不咬狼，咬向空气。／它急刹车」——「它」隔段漂到狼）。
- 抽象名词（疼/抖/血腥味）可以做主语，但不得顶替具体施事承担动作链。
- 机械判定：留空——本条无 prose-scan 特征，仅人工/评审执行；落点在卷积波次的「滚动回看」步逐句跑（kb/craft/convolution-waves）。

### R7 · 禁顶真电报腔（成文正文，用户口径 2026-09-22）

- 「X。X，……」式顶真链与连环无主语短句**不得当默认叙述腔**——事故句式：「就是除名。除名，家里断供，他爹的牌位挪出祖祠」（逗号当刹车、主语当装饰，是网文金句腔/AI 仿写指纹，不是狠劲）。
- 顶真作为修辞只在真正的刹车点使用，每章 ≤1 处，且复述位必须带语法桥（「除名之后」「一旦除名」），不许裸词开局。
- 因果推进优先写成完整句：主语显、连接词在位；短促感靠删修饰获得，不靠删主语获得。
- 机械判定：prose-scan 可加特征，顶真正则 `([汉字]{2,4})[。，！？]\s*\1[，。]` 计数（留待工具化）；当前由卷积波次「滚动回看」逐句执行。
