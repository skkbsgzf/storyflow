# 结构母型 · 逆袭/升级（欲望递进）

- **骨架**：底层起步 → 第一桶金 → 进入牌桌 → 掀桌。
- **强项**：爽点密度好布（神豪族主场），升级阶梯即卡点位。
- **风险**：升级只涨数值 = 单薄；须配代价梯（每次跃迁付一次不可逆代价）。
- **适配**：神豪 / 赘婿 / 系统流。
- **选型三步**与节奏市场对表见 `kb/structure/catalog`；hot 档偏此型；改造示例：金手指带成本。
- **不确定因素注入点**：选本型后须输出 ≥2 个反认知变量（牌桌规则/身份层），防纯数值流。
