# 结构母型 · 单元宿命（重复结构带变量）

- **骨架**：每单元同机制不同变量（模拟器 / 循环 / 接单）。
- **强项**：量产稳定、每单元自带钩。
- **风险**：变量枯竭即崩——须先建**变量清单**（≥10 个可轮换变量才敢开长线）。
- **适配**：系统流 / 模拟器 / 无限流。
- **选型三步**与节奏市场对表见 `kb/structure/catalog`；融合示例：升级×单元宿命；网文侧实态见 `kb/structure/episodic-webnovel`。
- **不确定因素注入点**：选本型后须输出 ≥2 个反认知变量（单元机制的例外一次在哪打破）。
