# 结构母型 · 双线交叉（明暗双线）

- **骨架**：A 线明面推进、B 线暗面汇聚 → 交叉点引爆。
- **强项**：中点反转天然位（交叉即反转）。
- **风险**：交叉间距失控——>5 拍不交叉判失衡（对照 `kb/aesthetic/pacing-density`）。
- **适配**：悬疑 / 商战 / 身份错位。
- **选型三步**与节奏市场对表见 `kb/structure/catalog`；calm 档偏此型；融合示例：复仇×身份错位双线。
- **不确定因素注入点**：选本型后须输出 ≥2 个反认知变量（谁在瞒谁/信息差方向）。
