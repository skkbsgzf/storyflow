# 结构母型 · 复仇（背叛→蛰伏→清账）

- **骨架**：冤屈建立 → 能力获得 → 逐层清算 → 终局对账。
- **强项**：目标清晰、爽点天然当众（清算即打脸场面）。
- **风险**：中段清算同质化——连打脸即疲劳；须做清算顺序改造（倒序/跳级）与代价梯。
- **适配**：熟龄复仇 / 赘婿 / 重生。
- **选型三步**（深挖·改造·融合）与节奏市场对表见 `kb/structure/catalog`；hot 档偏此型，每集爽点 ≥3。
- **不确定因素注入点**：选本型后须输出 ≥2 个反认知变量（人物前史/身份层/世界规则），例「她曾是黑道大小姐」「真假千金互换」。
