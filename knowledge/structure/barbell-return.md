# 结构母型 · 倒钩回归（宿命回环）

- **骨架**：开局即终局倒影，结尾回收开局。
- **强项**：余味深、二刷价值高。
- **风险**：前期钩子弱——短剧慎单用（首卡 8-12 集需另配强钩）。
- **适配**：深沉档 / 长线 IP。
- **选型三步**与节奏市场对表见 `kb/structure/catalog`；calm 档偏此型。
- **不确定因素注入点**：选本型后须输出 ≥2 个反认知变量（倒影里哪一处「对不上」）。
