# 登场桥段设计

**标尺**：冷开场不是「介绍」，是一场**自带结算的小型事件**。观众看完 90 秒，要自己得出关于这个人的结论——而不是听旁白告诉她。

## 一、三问必须先答（写桥段之前）

| 问 | 合格线 | 不合格样本 |
| --- | --- | --- |
| 她是谁 | 身份 + 一个反差（官职/性别/年龄/来历任一维度上的错位） | 只给名头和履历 |
| 她要什么 | 这一集内可见的具体目标（一笔账、一个人、一件物） | 「变强」「复仇」这类长期抽象目标 |
| 她凭什么狠 | 一个**画面级**证据：一招、一句、一个数字，且当场见效 | 旁人嘴里「她很厉害」 |

外加一问（防主角光环空转）：**她这一集付了什么代价？**（受伤 / 赔钱 / 得罪人 / 丢官身 / 失去一次机会，任选其一，必须可看见。）

## 二、桥段选材四条硬约束

1. **不与主线重复**：冷场做的事，正文不许再做一遍（同一类斩妖、同一类打脸）；它是主线的**旁证**，不是预演。
2. **可整块切掉**：删掉冷开场后正文必须还能连上（防止给后续集数挖依赖坑）。
3. **自带规则教学**：世界的一条硬线（力量怎么算、命怎么值钱、官身怎么约束人）在这件小事里被顺手演示，不许单开解说场。
4. **不引新人物进主线**：冷场角色用完即弃，或明确登记为后续某集的复用件。

## 三、接缝设计（本技能最容易翻车的地方）

冷场收尾抛出的钩子，必须被正文第一场**第一个画面或第一句台词**接住。三选一：

- **承人**：冷场里被救/被打脸/被记下名字的人，就是正文第一场的当事人；
- **承物**：冷场结算到的那件东西（赏钱、道行、信物、尸首、卷宗），正文第一场正在用它；
- **承账**：冷场结下的那笔账（仇家记住她了 / 上司要追责 / 百姓传开了），正文第一场来收账。

禁手：硬切黑屏＋旁白「与此同时」「几天之后」「话说」；用字幕交代时间地点跳转来掩盖接缝缺失；让主角在冷场和正文里做**同一个动作**（重复亮相=假接缝）。

## 四、分拍稿（交付形态）

按目标集的篇幅配额（如第 1 集 1200~1400 字）把冷开场切成 3~5 拍，逐拍给：

```
拍号 | 画面（只写可拍摄） | 功能（三问/规则/代价哪一项在这拍兑现） | 秒数 | 台词（≤2 句，声口对齐人物卡）
```

并写出：
- 前 3 秒的钩（第一拍的第一句/第一个画面，观众为什么不停手）；
- 收尾卡点（承接到正文哪一场，写出被承接的那场原句）；
- 备选方案一个（换桥段不换三问答案），说明为什么首选更好。

## 五、自检

1. 把冷开场单独给一个没看过任何材料的人，他能复述「谁/在哪/干什么」吗？
2. 三问 + 代价，是否每一项都能在剧本正文里指出**落在哪一行**？指不出=还在用旁白糊。
3. 冷场与正文第一场之间，删掉任一边是否都不影响另一边？（应该只影响承接句，不影响剧情。）
4. 台词声口：把人物卡里的口头禅/语气习惯对照一遍，冷场的她必须是正文的那个她，不许换人设。
