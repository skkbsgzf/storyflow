# 分集重排表

**标尺**：重排表不是分集简介。它的每一行都要能直接回答剧本师四个问题——这集拍什么、爽在哪、结尾为什么必须看下一集、交到这集末主角和配角各自的状态变了没有。

## 表头（每集一行，列不许缺）

| 列 | 口径 |
| --- | --- |
| 集号 | 第 N 集 |
| 段落 | 铺垫 / 展开 / 升级 / 收束（铺垫段末集必须标「展开点」） |
| 一集一事 | 本集唯一主事件，≤15 字 |
| 主爽点 | 五类之一（收服异兽/强化自己/濒死战斗/修炼晋级/地位提升）；填「无」需给豁免理由 |
| 辅爽点 | ≤1 个；第 3 个爽点出现即删 |
| 字数配额 | 按标尺段落口径给区间（第 1 集 1200~1400，其余按段） |
| 素材锚 | 原文出处（章号/原稿第几集第几场）+ 事实态/推断态标注 |
| 卡点 | 集末钩子一句话 + 类型（信息型/情绪型） |
| 交接 | 本集结束时：主角修为与道行 / 队友认知 / 敌方情报 三项各变了什么 |
| 砍留 | 原稿对应内容标注：保留 / 压缩为一句 / 后移至第 N 集 / 删除并说明去向 |

## 硬规则

1. **铺垫段是配额，不是意愿**：规定「前 K 集只铺垫 X」，则第 K 集结尾必须停在展开点（正反双方第一次正面相撞的那一瞬）。排表时先定第 K 集的卡点，再倒推 1~K-1 集，不许先排再凑。
2. **空窗记账**：任一主爽点连续缺席 ≥3 集的区间在表上标「爽点空窗」并写进交付自检报告——是否重排交评审与端尾人裁，空窗不自动判「表不合格」（09-24 阈值清剿）；全表五类爽点各至少 1 次落在铺垫段（若素材确实没有，写「素材缺口」并给出补料方案，不许静默缺席）。
3. **不许一集两件事**：一集里出现两个完整冲突（各自的起承转合），必须拆成两集；两个半冲突可合并为一集。
4. **递进可核**：同一信息/同一侧面在铺垫段最多出现两次，且第二次必须带增量。排表里体现为「侧面」列不重复堆叠。
5. **素材锚必须真读过**：锚到未读章节 = 违规。无锚的集（纯新增桥段）显式标「新增」，并说明为什么新增（通常是为了补爽点或补代入）。
6. **状态守恒**：交接列逐集串起来要对得上世界书集账与时间线；境界、道行、道具、知情范围不许无来源跳变。

## 铺垫段细排（前 10 集级颗粒度）

铺垫段每集额外给出：
- **三要素自检**：这一集单看，观众能否答出「谁/在哪/在干什么」；
- **主爽点的兑现画面**：具体到「哪个镜头/哪句台词/哪条字幕」把爽点拍到脸上；
- **代价**：主角或己方在这一集损失了什么（铺垫段全无代价 = 后面爆不动）。

## 交付前自检

1. 把表按段落汇总，铺垫段占了几集、兑现段占了几集，与甲方口径是否一致？
2. 随机挑三集（含第 1 集与铺垫段末集），只看该行能否让写手动笔？不能 = 列没填满。
3. 「砍留」列有没有一栏是空？空栏意味着原稿内容会被静默丢弃——这是改编事故的主要来源。
