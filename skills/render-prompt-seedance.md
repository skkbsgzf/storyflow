# Seedance 分镜提示词（引用语法）

适用于：把剧本/分镜表转成下给 Seedance 2.0 的画面生成指令（即梦/火山方舟）。提示词是**画面调度指令**而非文学描述：每一帧画面的来源、运镜、声音都要点名。

## 万能公式

```text
[主体/人物设定] + [场景/环境] + [动作/运动] + [运镜语言] +
[分时段描述] + [转场/特效] + [音频设计] + [风格/氛围]
```

## 硬规则

1. **@ 引用必须点名定岗**：`@图片1 作为首帧`、`形象参考@图片2`——只写「参考@视频1」是引用模糊，必错；
2. **运镜用固定词库**：推/拉/摇/移/跟/环绕/一镜到底/希区柯克变焦/低角度仰拍/鸟瞰；景别：极致特写→特写→中近景→中景→全景→远景；
3. **分时段描述**（≥8 秒强烈推荐）：`0-3秒：… 4-8秒：…`，复杂度和时长匹配；
4. **音频写进提示词**：BGM/音效/台词/旁白都要给（Seedance 自带音效配乐）；
5. **角色一致性锁图**：角色设定图定稿后，所有关键帧引用同一张（`人物形象参考@图片N`）；
6. **素材上限**：图 ≤9（<30MB）、视频 ≤3（各 2-15s/<50MB）、音频 ≤3（<15MB）、总 ≤12 个；生成 4-15 秒；**不支持写实真人脸素材**。

## 单镜头模板（图生视频）

```text
@图片1 作为首帧。人物形象参考 @图片2。
[动作起点]→[动作发展]→[反应]，镜头从[景别]缓推/拉至[景别]。
BGM：[___]；音效：[___]。电影级质感，[色调]。
```

## 15 秒分时段示例

```text
@图片1 作为首帧。形象参考@图片2。
0-3秒：雨夜便利店门口，林晚撑伞静立，伞沿低垂；
4-8秒：镜头缓推至脸部特写，雨水沿伞骨滴落，眼神由错愕转冷静；
9-12秒：她收伞，向黑色轿车走近两步（车身入画）；
13-15秒：定格在车窗内模糊人影，雨声渐弱，风铃一声。
BGM：低沉钢琴单音；音效：雨声、风铃。
冷蓝色调，浅景深，电影级质感。
```
