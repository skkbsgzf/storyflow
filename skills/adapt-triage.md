# 改编反馈诊断

一句话定位：**反馈是症状，原稿是病人，本技能的产出是CT报告 + 手术方案，不是止痛药。**

## 硬纪律（先查这几条，全中才算做完）

1. **逐条对账，不许笼统**：甲方每一句反馈都要有归宿——落成病灶，或写明「不采纳 + 理由」。禁止「已充分考虑」。
2. **病灶必须带位置**：`文件:行号` 或 `第N集第M场`，并**引原文 ≤2 行**。没有位置的诊断一律作废（参照 revision-loop：反馈必须 actionable）。
3. **一轮改透三处 > 三轮各摸一遍**：病灶按「影响观众数」排序，取 **最差五处**进手术方案，其余记入「备查」，本轮不动。
4. **不改动清单与改动清单同权重**：原稿里已经做对的（该保的台词、该保的卡点、该保的结构）逐条列出并注明「保」。改编最大的失败模式是顺手改坏好件。
5. **原文事实与推断分两态**：涉及原著素材的判断，未读过的章节不得当依据；缺料要写明「素材缺口，需取第 X 章」。

## 三步产出

### 第一步：爽点盘点表（本技能的核心件）

对原稿逐集打分，四类标记：

| 列 | 口径 |
| --- | --- |
| 主爽点 | 该集真正兑现的是五类中的哪一类（收服异兽/强化自己/濒死战斗/修炼晋级/地位提升），无则填「无」 |
| 兑现形态 | 可见画面 / 字幕报数 / 他人反应 / **仅旁白宣称**（最后一项=空转，直接立案） |
| 强度 | 强（有代价或有反转）/ 中 / 弱（一句带过） |
| 空窗 | 连续多少集没有该类爽点 |

盘点完必须回答三个数：**五类爽点各自出现了几次；最长空窗是第几集到第几集；哪一类全程缺席**。这三张数就是「避重就轻不足」的量化证据。

### 第二步：病灶账（分级）

- **A 级（结构病）**：题材卖点错位、铺垫段与兑现段配比失衡、主角出场过晚、集末无有效钩子；
- **B 级（单集病）**：代入三要素缺失（谁/在哪/在干什么答不出）、爽点空转、信息重复三遍、过渡场占篇幅；
- **C 级（句面病）**：不可拍摄内容（心理描写/抒情）、台词腔、AI 味。

每条格式：`级别 | 位置 | 原文摘句 | 病灶 | 动作（砍/移/补/换/压缩为一句） | 依据（引标尺条款）`。

### 第三步：改编取向（写给下游的约束，不是愿望清单）

- 篇幅与集数怎么切（配额表口径，逐段给数字）；
- 哪几场戏升级为整集、哪几场压缩为一句、哪些原文信息允许后置；
- 主角登场方式（冷开场桥段的选材方向与接缝要求）；
- 素材缺口与取料清单（要哪几章、用来补哪类爽点）；
- 明确写出「本轮不动的东西」。

## 自检（交付前自问）

1. 甲方最狠的那一句（如「看不懂、没代入感」）我是不是真的用一个可核的判据接住了，而不是用一段漂亮分析绕过去了？
2. 病灶账里有没有一条是「原稿某处其实很好，但下游容易改坏」？没有说明我只在挑刺，没在守件。
3. 爽点盘点表的三个数，任何一个答不出 = 本技能未完成。
