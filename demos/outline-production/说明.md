# 官方 Demo · 分集大纲与编排工作流（outline-production）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 大纲化流水：已验收选题方案 → 三线骨架与分集功能表（默认 60 集）→ 红队冷读者测试（节点可预测死点）→ 人工验收 → 可拍分集大纲
- 红队「冷读者」口径：没读过方案的路人按集数猜剧情，猜中即死点

## 怎么跑

```bash
python -m core miniflow flow_run --flow outline-production --project <你的项目id>
```

## 先看哪些文件

1. `选题方案.md` —— 输入（必须是已过验收的选题方案；demo 附了节选样例）
2. `项目配置.json` 里 `episodes`（总集数）与 `route`
