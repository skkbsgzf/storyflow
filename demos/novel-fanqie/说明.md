# 官方 Demo · 番茄快餐网文工作流（novel-fanqie）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 四阶段流水的完整体验：S1 发散聚合（找梗/组装/ Zeitgeist 解剖默认关）→ S2 世界观底座 → S3 轻量大纲 → S4 迭代成稿（三章）+ 去 AI 味终稿
- 每阶段的验收门：S1/S4 是你（用户门），S2/S3 是红方 agent 复核

## 怎么跑

```bash
python -m core miniflow flow_run --flow novel-fanqie --project <你的项目id>
```

每跑一轮，刷新 workflow.html 看画布推进；节点出产物后直接在右侧文档页里改、框选批注提意见。

## 先看哪些文件

1. `选题素材.md` —— 你的开题输入（整篇可替换）
2. `项目配置.json` —— 题材/需求/风格契约（flow_run 自动装载）
3. 跑完 S1：`梗卡.md`、`选题分析报告.md`；跑完全程：`章节正文/第1-3章.md`
