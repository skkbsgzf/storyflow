# 官方 Demo · 短剧成稿生产线（topic-selection）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 五阶段菱形循环：S1 调研 → S2 结构 → S3 大纲 → S4 小纲 → S5 成稿，每阶段红方四视角（目标读者/一般读者/资深编剧/甲方）逐段验收
- 双版本路线（route=dual）：爽版 / 合理版 + 基线对照
- 验收不通过按根因打回本阶段入口定点重做

## 怎么跑

```bash
python -m core miniflow flow_run --flow topic-selection --project <你的项目id>
```

## 先看哪些文件

1. `选题素材.md` —— 甲方需求输入（整篇可替换）
2. 跑完 S1：`选题分析报告.md`、`选题方案.md`；S3 后：`分集大纲`；S5 后：`对外交付/` 分集小纲
