# 分集大纲 · demo（已验收样例）

> 输入约定：本流消费的是**已过验收**的分集大纲。以下为三集样例（节拍口径：竖屏短剧 1.5-2 分钟/拍）。

## 第 1 集《签字》

- **钩子**：汛期凌晨，巡堤员在堤脚发现渗水，拍照上报——照片在群里被撤回
- **节拍**：老周巡查发现管涌前兆 → 群里报险被红色 撤回 → 电话打给主任被『按流程』挂断 → 老周掏出私人手机拍第二组照片 → 钩子：照片里堤脚有一只不属于任何施工队的雨靴
- **功能**：立主角（较真）、立危机（渗水）、立反派轮廓（撤回指令的人）

## 第 2 集《台账》

- **钩子**：施工方连夜补料，账面『合格』——老周翻开三十年台账，同期同桩号的记录对不上
- **节拍**：补料现场 vs 台账原始记录交叉 → 主任施压『老周你要考虑退休』→ 女儿劝辞职 → 老周把台账复印件寄出 → 钩子：寄丢，快递显示『已签收』，签收人：项目部

## 第 3 集《听证》

- **钩子**：物业费听证会变成老周声讨会——他掏出的不是意见书，是三十年维修台账
- **节拍**：听证会攻防 → 台账页码与工程日志逐条对撞 → 撤回指令的人现身（项目部技术顾问）→ 钩子：顾问西装口袋里，露出与老周同款的旧雨靴
