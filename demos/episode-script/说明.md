# 官方 Demo · 分集剧本流水工作流（episode-script）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 剧本化流水：已验收分集大纲 → 逐集任务包（台账切片注入 → 分拍写作 → 断言+台账双校验 → 红方抽检）→ 批量人工验收
- 产物格式：竖屏短剧分拍剧本（拍号/景别/台词/时长口径）

## 怎么跑

```bash
python -m core miniflow flow_run --flow episode-script --project <你的项目id>
```

## 先看哪些文件

1. `分集大纲.md` —— 输入（必须是已验收大纲；demo 附了三集样例）
2. `项目配置.json` 里 `range`（集数范围）与 `batch`（单批集数）
