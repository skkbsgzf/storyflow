# 官方 Demo · 长篇网文生产工作流（novel-longform）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 长篇流水：需求 → 三层问答开书（World Bible / 世界圣经）→ 卷纲与章功能序列 → 逐章生产（台账切片 → 章回写作 → 断言+台账双校验 → 红方抽检）→ 批量人工验收
- 中间件（世界书）在长篇里的用法：设定真相先入册，成稿消费

## 怎么跑

```bash
python -m core miniflow flow_run --flow novel-longform --project <你的项目id>
```

## 先看哪些文件

1. `需求.md` —— 一句话需求 + 展开（可替换）
2. 跑完开书：`世界圣经.md`；逐章阶段：`章节正文/`
