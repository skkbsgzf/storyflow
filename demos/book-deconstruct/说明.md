# 官方 Demo · 拆书入库工作流（book-deconstruct）

这是**可直接跑通的示例项目**：配置已填好、输入已就位，导入后即可开跑。

## 这个 Demo 演示什么

- 拆书流水：参考作品 → 读前识别 → 六槽位拆解（设计层×细化层×文风）→ 组合查重 → KB 候选条目 → **人工确认入库**（拆书是唯一写知识库的流，入库前必过你的确认门）
- 「单篇观察」模式：一篇范文拆全槽位；同类型 ≥2 篇可做类型共性，≥3 篇可跨类型

## 怎么跑

```bash
python -m core miniflow flow_run --flow book-deconstruct --project <你的项目id>
```

## 先看哪些文件

1. `参考作品.md` —— 拆解对象（demo 附原创范文，正式使用请替换为你有权的文本）
2. `项目配置.json` 里 `sources`（观察模式）与 `slots`（槽位范围）
