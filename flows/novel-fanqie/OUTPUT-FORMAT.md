# novel-fanqie v2 · 产出物格式规范（单元剧 / 番茄快餐网文）

## 输出纯度（铁律 · 全部产物适用）

**正文只写面向读者的内容。** 过程元数据不进产物文件，只进宿主思维链与 journal 留痕：

- 禁入正文：节点名（tropes/outline3/...）/ skill 名 / 轮次 rN / route 参数 / kb 引用 / 输入清单 / 隔离声明 / 合规自查过程 / 数据快照口径 / 「大纲轻量三件」式自注；
- 需要交代的数据与依据，**转译成叙事**（「近期同类题材均热度过亿」「市面成熟流派已验证」），不列参数、不写来源路径；
- 自查口诀：把正文读给读者听，出现「skill / kb / 节点 / r8 / route / 声明」即为污染。机械校验：`python tools/check-purity.py <project>`。

## 产物格式

- **梗卡.md**（tropes）：查族结论 → 主梗/辅梗选型（反差面/真相面/机制翻译）→ 前三章预布点表 → 演化链新变体落点。全部叙事化。
- **单元剧大纲.md**（outline3）：暗线节点表 → 单元序列 → 逐章细纲。表头用读者视角字段（位置/抖什么/读者新认知），不用内部代号。
- **章节正文**（ch1/ch2/ch3）：正文即正文，章末钩子；无元注释。
- **世界观/**（w-*）：设定条目面向写作者引用，条目内不含执行过程。
