# flows · 按用途归一的生产线模板（flow@3）

| 目录 | 用途 | 产物 |
|---|---|---|
| `screenplay` | 短剧剧本生产线：选题 → 世界观 → 结构/编排/分场 → 剧本 | 剧本.md |
| `novel` | 长篇小说生产线：大纲 → 章节成稿（含卷积波次成文） | 终稿.md + 章节 |
| `prose` | 成文流水线（被 novel 引用的专科层）：三层稿 → 拼装 → 打磨 | 章节正文 |
| `topic` | 选题生产线：报告 → 套路 → 素材解构 | 选题报告.md |

命名纪律：目录名 = flow id = 用途；不带题材、不带项目细节。题材由运行时输入（direction）注入。
新增生产线：拷贝最接近的用途流，改 id 与节点，跑 `python tools/flow-lint.py flows/<目录>/flow.json` 过 0 error。
