# 短剧成稿生产线（topic-selection）· 产出物格式规范

> 流程推演：S1 调研 → S2 结构 → S3 大纲 → **S4 小纲（doc·可批注回流）** → S5 成品剧本。每阶段独立产物与产出格式，红方四视角逐段验收，打回按根因级联。
> **对外交付四件套**干净、模板化、客户可直读；内部过程物件（意见书/断言/梗卡/对账表/基线）不随对外输出。

## 输出纯度（铁律 · 全部产物适用，含内部过程物件）

**正文只写面向读者的内容。** 以下过程元数据一律不进产物文件——它们属于宿主思维链与 journal 留痕：

- 执行元信息：节点名 / skill 名 / 版本号 / 轮次（rN）/ route 参数；
- 输入清单：读了哪些文件、哪些 kb 条目（`输入：xxx.md + kb/...`）；
- 执行声明：读没读某目录、有无 git 操作、隔离声明、合规自查过程、件型声明；
- 数据快照的原始口径（语料库版本/解析部数/均热度）——需要时**转译成叙事**（「近期同类题材均热度过亿」）。

> 自查口诀：把正文读给目标读者听，出现「skill / kb / 节点 / r8 / route / 声明」即为污染。机械校验：`python tools/check-purity.py <project>`。

## 对外交付四件套

### ① 01-选题报告.md（S1 · 含调研）

叙述先行，禁止内部术语（无阶段号/断言号/kb 引用）。章节：我们要讲一个什么故事 → 为什么是现在（实事锚点）→ 观众是谁 → 市场上有过什么成功经验 → 能做成什么样（体量/形态/边界承诺）→ 一句话提案。

### ② 02-大纲.md（S2+S3 · 含方案细节）

六节：故事梗概 / 人物（每名含语言卡）/ 主线与暗线结构（双线各自成表）/ 分集编排（表）/ **情感线设计**（≥3 条：起点/转折/兑现/情绪关键词 + 曲线主辅型，对表 `kb/aesthetic/emotion-curve`）/ 后续走向。数据与对标以叙事方式呈现，不列内部参数。

### ③ 03-小纲.doc（S4 · 分镜脚本 · doc 格式 · 可批注回流）

**用途**：客户批注载体。逐分镜给到"场景 / 人物行动 / 台词"，**达意即可、无需打磨**（打磨留给成品阶段）；文末必附**创作思路页**（逐段说明为什么这么写——批注的坐标系）。

分镜条目格式：
```text
第X集 · 分镜 N
场景：地点/时间/在场人物
行动：人物在做什么（可执行，一两句）
台词：角色名：说什么（口语，达意）
备注：道具/转折/伏笔标记（如有）
```

纪律：每集 9-12 分镜、每镜一个认知更新、编号连续可锚定；分镜时长（6-15s）与集末钩位在时长/备注字段内部执行，不进批注视图。

**可选模块 · 批注回流**：客户在 doc 上批注/修订后回传 → `docx_ingest`（待实现 minitool）解析批注与修订 → 结构化意见清单（锚点=分镜号）→ 成品剧本基于改后版本产出，意见逐条落实或在变更记录说明不改原因。无回传时按小纲原样进入成稿。

### ④ 04-成品剧本试稿.md（S5 · 连贯剧本）

基于小纲（或批注后版本）产出。格式模板：`templates/剧本试稿模板.md`。

- **连贯剧本**：场次头 + 人物行动/表情（连贯段落）+ 角色台词（独立成行、按角色归组）。
- **特殊镜头与旁白用中括号备注**（一行一条：慢镜/旁白/转场）。
- **角色台词按角色标注**——画本上色阶段按角色分色，角色名不得错。
- **不出现任何内部标注**：无钩型/时长/尾钩/拍号/档位字样；拍级纪律（6-15s、钩子不断链、每拍一个认知更新）在内部执行——格式上看不见，节奏上摸得到。
- 成稿后强制过 `dialogue-polish`（台词去AI味三遍校准：人物声口/处境/清单）再进 R4'。

### 基线对照件（route=dual 时）

04-成品剧本-基线.md：无监管对照件，结构同构，供增益验证。内部备查，不进交付页主视图。

## 内部过程物件（不随对外输出）

多视角意见书-R1~R5（内部/ 目录）、硬断言报告.json、梗卡、约束对账表、基线对照件、台词打磨对照表。它们是流程的质量证据，留在项目文件夹备查——**甲方看到的只有四件套与交付页**。

## 验收口径（总）

1. 各阶段红方共识判定 = 过，任一"弃"不得进入下一阶段；
2. 断言报告 block = 0（机器层，含 C10 三分钟测试、梗点密度）；
3. 对外交付四件套格式合规：报告叙述先行、大纲六节齐、小纲逐分镜可锚定、成品剧本无内部标注；
4. 创新亮点回指调研依据——假新意打回；
5. 台词打磨对照表与批注落实记录齐备（内部备查）。
