## V4-1 · 三段式框架重构（框架层，先行）

**目标**：标题栏 + 44px 图标栏 + **总览面板 ∥ 详情面板**（右侧滑入）三段式；弹性收起（参考 dsh/obsidian/zcode——不是硬返回键，是可折叠的分区）；**主面板内零弹窗**（详情一律右侧滑入，只有页面跳转）；右侧主内容区支持**并行 doc 面板**（多文档并排分栏）。

**任务分解**：
1. 布局重构：总览面板（列表/卡片/时间线）+ 详情面板（滑入式，带弹性收起把手——拖拽宽度记忆 localStorage）；详情关闭 = 弹性收起回总览
2. 并行 doc 面板：主内容区支持 doc 分栏（1+1 / 1+1+1，拖拽分栏比），从大纲/世界书「在分栏打开」
3. 配置入口改右上角按钮 → **二层抽屉**（一层=导航 tab：模型/日志/历史/偏好/插件；二层=各 tab 内容页；经典抽屉返回栈）
4. 主区零弹窗改造：v3 的详情弹层全部改滑入详情面板；确认类操作（恢复快照）保留模态确认（唯一豁免）

**验收标准**：
- [ ] 总览 ⇄ 详情双向滑入/弹性收起，宽度记忆；主区无遮罩弹窗（模态确认豁免）
- [ ] 并行 doc 分栏 ≥2，拖拽比例记忆
- [ ] ESC 语义分层（抽屉二层→一层→关闭）
- [ ] 零外部资源、幂等、payload 不变（纯前端重构）

**估算**：3–4 天 ｜ **风险**：并行 doc 与约束模式（strict 档提示）的展示位需要设计

## V4-4 · LocalHistory（VSCode 式，依赖 D-4b=恢复编辑）

**目标**：默认开启的本地编辑历史——diff 形式存本地、定期保存、设置页查看与回滚。

**任务分解**：
1. 编辑回归：文档面板 FS API 写通道回归（v3 移除的），编辑落盘前自动存 LocalHistory
2. 存储机制：项目 `.history/<文件路径哈希>/`——每次保存存 unified diff（对上一版），基线为全文；**对接 Pinax intervalWords 口径**（按字数间隔定期保存，默认 500 字可配）——FS API 场景由页面定时器+字数计触发
3. 设置页「本地历史」tab：按文件分组的时间线、diff 查看、恢复到任意版（生成反向 patch 确认应用）
4. 与 snapshots/ 的关系：LocalHistory=细粒度编辑史（看板域）；snapshots=生产线留档——两轨并存，面板互链

**验收标准**：
- [ ] 编辑 md → 自动出 diff 存档（字数间隔触发可配）；关浏览器重开历史仍在
- [ ] diff 查看（并排/行内）+ 恢复到任意版（反向 patch 确认应用）
- [ ] 默认开启、可在偏好关闭；存储路径可配置
- [ ] 断网/本地全功能；幂等纪律不适用于历史（时序数据）

**估算**：3 天 ｜ **风险**：FS API 权限生命周期（会话级授权重开需重授——文档写明）
