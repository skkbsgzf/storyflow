## 三、能力面实况（接入方视角，不含未做的）

- **MCP**：27 tools ＋ 4 资源模板（`wb://{project}/graph`、`wb://{project}/entry/{id}`、`flow://{project}/state`、`artifact://{project}/{+path}`）＋ 2 prompts（`review-worldbook`、`gate-assist`）。资源正文只读登记表内的产物；单次回显 `LIST_CAP=300`，超限显式 `truncated`。
- **HTTP v1**：19 个入口（`/api/v1` 自述、`/api/v1/verbs`、`POST /api/v1/verbs/:verb`、`GET /api/v1/openapi.json` ＋ 15 条数据面）。成功 `{ok:true,data,meta}`，失败 `{ok:false,error:{code,message,detail?},meta}`，`meta.route` 回显表内那一行。
- **OpenAPI**：`contracts/http-openapi-v1.json`（生成物）与运行时端点同源；`--check` 会抓「注册了没写文档」「文档写了没注册」「动词必填参数没进 schema.required」三类漂移。

## 四、偏离与决策（卡面 ≠ 盘面的四处，全部有理由）

1. **SDK 版本**：卡面写 1.7，盘面实装 **1.30.0**（`package.json` 声明 `^1.7.0`）。按 1.30 真实签名落码（`registerResource` 四参重载、`ResourceTemplate` 的 `list` 位、`registerPrompt` 的 `argsSchema`、`resources/templates/list` 与 `resources/list` 是**两个** RPC——测试因此改用 `client.listResourceTemplates()`）。
2. **资源 URI**：卡面 `wb://graph` 这类前缀名落不了地（世界书/运行态/产物全是项目级数据），实现为带变量的模板；`{path}` 匹配不到含 `/` 的产物路径，改 `{+path}`；变量百分号编码进出（SDK 不解码），解码单点 `decVar`。
3. **旧路由不做 301**：`POST` 走 301 会被降级成 GET（写操作静默改语义），且 legacy 载荷被仓内 **11 个文件**按字段直读（`adapter/storyflow-client.mjs`、`storyharness/` 多处、`tools/workflow-page-template.html`、`tools/page-lint.mjs`）。改为 `deprecation: true` ＋ `successor-version: /api/v1` 响应头，载荷零改动。
4. **两处刻意的「不镜像」**：① v1 的 `/state` **不做** `run-state.json` 回落（旧项目归 legacy 面，v1 直接 `404 NO_RUN`）；② legacy 动词直通**不加** zod 校验（形状已冻结，加校验＝改语义）。另外 `resolveProjectFlowId` 把「state.json 损坏 → 500」改为「回落 → 报 NO_FLOW」，让报出来的错是能修的那个。
