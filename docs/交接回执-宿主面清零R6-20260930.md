## 四、这轮真正改变的行为（其余是等价换管道）

1. **`agent.ts` 七个公开函数首参由路径字符串改 `kernel`** —— 破坏性签名变更。全仓直接 import 者只有 `core/test/agent.test.ts`（已同步）；`storyharness/` 用自有副本、`adapter/` 走 HTTP，**外溢面实测为零**。
2. **`export const agentMcp` 单例下架，改 `mcpFor(kernel)` 按注入盘分桶** —— 默认 Node 盘仍映射到同一实例，现网 HTTP 逐字节不变；这一条关掉的是「注入盘上的宿主残留」：原单例构造时不带 `fs`，配置读取会回落宿主盘。
3. **`flow_lint` 子进程 cwd 由「projectDir 上跳两级」改 `kernel.repoRoot`** —— 默认盘面（`root === repoRoot`）同值；分离数据根的宿主上只有仓库根有 `tools/flow-lint.py`。
4. **静态面读盘改 `kernel.fs.stat` ＋ `readBuffer`，出口按 Fastify 惯例包 `Buffer.from(…)`** —— 发出字节不变。
