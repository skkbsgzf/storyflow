# 工单 · 看板 v3 规格（2026-10-13，用户定盘）

> **定位**：静态自包含 HTML，双击打开无需服务，本地化项目的唯一前端可交互件。
> **三不原则**：不写代码、不教怎么用、不讲废话。
> 用户原话规格全文见下节；本节先落四条实施裁定（规格内矛盾与数据缺口的消解）。

## 实施裁定（规格矛盾的消解）

1. **主题默认值矛盾**（§一 暗色 #16181d vs §十三「默认偏淡白灰青」）：实现 **CSS 变量双主题**——暗色（§一 色板）为默认，浅色「白灰青」为备选主题；偏好面板可切换 + localStorage 持久化。§十三 的「主题色选择（金/蓝/绿/紫）」实现为强调色四选。
2. **文档阅读只读**（§8.3 明确「不支持编辑和保存」）：v2 的编辑三通道在 v3 看板中**移除**（serve 的 PUT `/api/panel/files` 端点保留为 API 原语，不做看板入口）；看板回归纯展示。iframe 嵌项目 html 一律 `sandbox="allow-scripts"`（内联 JS 可跑、无同源特权）。
3. **数据源映射裁定**（规格引用的键 → 实际来源）：
   - `D.worldbook.entries/relations` ← graph.json / worldbook 索引聚合（v2 已有链路）
   - `D.artifacts[]` ← project-index.json（human+generated 全量，§3.3 的排除清单在前端过滤）
   - `D.chronicle.events/lanes` ← tools/chronicle.py 产物（5W1H/矛盾标注/多轨，v2 已接）
   - `D.config.models` ← 项目配置.json 非敏感字段 + .external/storyharness.json 的 provider/model 名（**脱敏：apiKey 绝不入 payload**——看板可公网分发）
   - `D.config.logs` ← journal.jsonl 尾部 ≤1000 条（time/level/msg）
   - `D.config.snapshots` ← snapshots/ 目录最近 ≤50 个（time/name/hash）
4. **产生源治理顺带**：dashboard 冒烟与验收产生的临时项目用固定 id（`p-dash-smoke`），用后即删。

## 用户规格原文（照录，实施以此为准）

### 一、设计风格

**参考对象**：Obsidian / Cursor / DeepSeek Harness

**视觉特征**：暗色主题，低饱和度，高对比文字；紧凑布局，信息密度高，控件间距小；无装饰性元素，无圆角过大，无渐变，无阴影；功能即视觉——图标按钮、紧凑列表、直接可达。

**字体栈**：中文优先用系统默认，英文用 Inter/系统默认，代码用等宽字体。

**色彩规范**：
- 背景：深灰黑 `#16181d`；面板：略浅 `#1d2027`；边框：暗灰 `#2a2e37`
- 主文字：暖白 `#d8d4cb`；辅助文字：灰色 `#8a8375`
- 强调色：金色 `#e8b33d`；功能色：蓝 `#6ea8fe` / 绿 `#5f9c7a` / 红 `#d98a83`

### 二、信息架构

**三栏式**：顶部标题栏（项目名 + 右侧配置按钮）；左侧工具栏（图标列，宽 ~44px，功能直达）；主内容区（面板渲染，居中流式）。

**左侧工具栏（从上到下）**：

| 图标 | 功能 | 说明 |
|---|---|---|
| ◻ | 世界书 | 词条列表 + 关系图谱 |
| ◎ | 人物档案 | 人物卡片浏览 |
| ☰ | 大纲 | 产物目录浏览 |
| ⊕ | 大事记 | 时间线浏览 |
| ◈ | 文档阅读 | 直接打开项目文件 |
| ⚙ | 配置 | 模型、日志、历史产物 |

**交互规则**：点击图标 → 主内容区开面板；再点已激活图标 → 关闭（回空白）；ESC 关当前面板；未激活灰、激活亮 + 左侧金色竖线（`border-left: 2px solid #e8b33d`）；图标 SVG 内联（零外部依赖）。

**主内容区**：同时只显示一个面板；切换 = 清空重渲染；面板内可滚动可交互。

### 三、各面板规格

**3.1 世界书面板**：顶部搜索框（标题/摘要/标签）+ 分类下拉；列表按分类分组可折叠，组内字母序；词条行 = 标题（粗）+ 标签胶囊 + 时间（灰）；点击出完整内容（标题/分类/摘要/标签/更新时间/路径）。顶部「图谱」按钮切 Canvas 力导向图：节点按分类着色、拖拽节点/滚轮缩放/拖画布平移；点节点 → 列表模式定位。数据：`D.worldbook.entries[] + relations[]`。

**3.2 人物档案面板**：搜索人物名/角色名；卡片网格 2~4 列自适应；卡 = 人物名（大）+ 角色定位（灰）+ 状态点（绿/金/红 = 活跃/草稿/退役）+ 标签胶囊；点击出完整信息（关系/出场次数/更新时间）。数据：`D.worldbook.entries[]` 过滤 `cat=="人物"`。

**3.3 大纲面板**：产物清单按目录层级组织成树；文件夹展开/收起；文件节点图标区分类型（剧本/小说/产物）；节点 = 文件名 + 状态标识 + 时间；文件点击 → 文档阅读面板打开。**不展示**：诊断报告、registry 文件、编译产物。数据：`D.artifacts[]`。

**3.4 大事记面板**：垂直时间线按时间序；时间块金色标签；事件 = 人物（蓝）· 简述；点击出完整 5W1H；矛盾标注事件红色。**不展示**：叙事层导语、段带导语。数据：`D.chronicle.events[] + lanes[]`。

**3.5 文档阅读面板**：类 doc 排版（居中 720px、字号 15px、行高 1.8、段距 12px、代码块暗底边框、粗体金色）。路由：.md → Markdown 渲染 / .html → iframe 直读 / .txt → 纯文本 / .json → 无预览提示。顶部路径栏显示当前路径。

### 四、配置面板（右侧抽屉滑入，宽 ~500px）

- **模型配置**：列表（名称/当前值/编辑/重置）+ 添加 + 批量重置默认；类型：字符串（API 端点/模型名）、整数（温度/max token）、开关（缓存）、数组（消息模板每行一个）
- **日志**：时间倒序；行 = 时间戳 + 级别（INFO 蓝/WARN 金/ERROR 红）+ 消息；级别筛选 + 内容搜索 + 可复制
- **历史产物**：快照按时间倒序（时间/产物名/状态）；点击预览历史版本；「恢复到此版本」需确认弹窗
- **偏好**：字号滑块（12~20px）、行高滑块（1.4~2.2）、主题色（金/蓝/绿/紫）、紧凑模式开关；localStorage 持久化

### 五~六、数据结构与状态

状态对象：`{activeTool, activePanel, docPath, config:{fontSize, lineHeight, themeColor, compact}}`。payload 扩展：`meta.layout_version:"3"` + `config:{models,logs,snapshots}`。

### 八、交互规则

工具栏：点击开/再点关/ESC 关/双击快速切换。面板内：列表点击看详情、搜索实时过滤、折叠切 class、图谱拖拽复用 v1、恢复需确认。文档阅读：可选中复制、Ctrl+F 原生搜索、**只读不支持编辑保存**。

### 十、性能边界

| 指标 | 阈值 | 策略 |
|---|---|---|
| 词条数 | ≤200 | 列表 O(n) 过滤 |
| 图谱节点 | ≤200 | Canvas 力导向 60fps |
| 文档字节 | ≤200KB | 直接渲染 |
| 日志条数 | ≤1000 | 分页/虚拟滚动 |
| 历史快照 | ≤50 | 列表渲染 |
| 总 payload | ≤500KB | 模板内联 JSON |

### 十一~十二、硬约束

零外部资源（CSS/JS 内联、SVG 内联图标、系统字体栈）；幂等（同 payload → 同 HTML，不携带生成时刻，排序稳定）。

### 十三、CSS 变量

支持用户导入配色，多主题全局应用（默认与备选的裁定见顶部实施裁定 1）。
