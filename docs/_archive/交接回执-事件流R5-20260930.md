## 四、偏离（照 CHANGELOG 的 D-R5 表，验收对着这张表，不对着代码猜）

1. **不建 `FlowEvent`**：盘上类型名是 `AgentEvent`，扩它那一个联合。`docs/integration/sse-events.md` 在 R4 前就写了这条提醒。
2. **`verbs.ts` 未动**（卡面写集点名 VerbContext）：事件源选 journal 台账。选了内存总线 = 第二套真相，且 CLI 起 run、HTTP 在看这种跨进程场景收不到。
3. **FS1 没有 §4.2**：章节到 §3.3 为止，其后是「四、注入纪律」（无子节）。门禁口径按 §3.2 ＋ §3.3，已在 §3.2 末留说明。
4. **卡面写集 6 个文件 → 实际 2 新增 ＋ 4 修改**：通用 helper 必须有家；`http.ts` 排在 R6 批三，把投影表塞进去等于给要退役的宿主面当地基。
5. **「行为不变」之外多修了两处既有缺陷**：`req.raw` 的 `close` 在 POST 上过早触发（连接被静掐，实测只有 `open` 帧抵达）；`await it.return()` 对卡在长 await 的源永挂（会把 HTTP 连接钉死）。留着不叫行为不变，叫行为不变地坏着。
6. **`heartbeat` 对对话流是新增帧**：兼容底线是「未知 `type` 忽略」，仓内两个消费方已核对（`adapter/storyflow-client.mjs` 逐帧转发；`storyharness/src/home.ts` 的 else-if 链落默认分支）。
