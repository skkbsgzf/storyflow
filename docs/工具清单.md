# miniflow 工具清单（kit 工具总目）

> 覆盖范围：`tools/*.py`（L1 命令行工具）、内核内建 minitool（零 token，进程内）、内核 CLI 动词（七动词 + 扩展）。
> 约定：所有 Python 工具**零第三方依赖**（标准库 only）、从仓库根运行、`--help` 自描述；新增工具必须登记进本清单。
> 更新：2026-09-19 ｜ 校验方式：`python -m py_compile tools/*.py` ＋ `python -m unittest discover -s tools/tests`（判定型工具 19 例）

---

## 一、L1 命令行工具（tools/*.py）

### 项目运行与状态

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **whereami.py** | 开工自检（铁律 #1）：回答"我在哪"——项目 / flow / 焦点节点 / 必读输入 / 应产输出 / 门状态。多项目歧义返回类型化 `AMBIGUOUS`，禁止静默猜测 | `python tools/whereami.py [--project <id>]` |
| **snapshot.py** | 快照与重跑工具链：产物不可变副本（`snapshots/<node>/r<N>/`）+ 索引（hash/时间/输入指纹）+ 版本 diff | `python tools/snapshot.py capture <flow> <project> <node> --files <f1,f2> [--note]`<br>`python tools/snapshot.py diff <project> <node> --a <round> --b <round>` |
| **project-pages.py** | 工作流页面生成器：单文件 HTML（拖拽画布 + 文档面板 + 批注气泡 + 意见簿），全项目 md 自动收纳。**flowId 以项目 state 绑定为准，传错即 ABORT** | `python tools/project-pages.py <flowId> <projectId>` |

### 质量与校验

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **validate-kb.py** | 知识库校验：索引↔文件对账、断言表完整性、技能↔minitool 绑定检查；并确定性重建 trope/benchmark 条目 | `python tools/validate-kb.py` |
| **check-purity.py** | 产物正文纯净度（AE-OUTPUT-PURITY，block）：扫描执行元数据污染行（节点/skill/轮次/kb 引用/输入清单/声明类）。命中即 exit=1，可接校验链 | `python tools/check-purity.py <project> [file...]` |
| **flow-lint.py** | 流程图静态校验（命名规范 + 结构完整性）：transform 三前缀合法性、skill/core/sm 登记核对、entry/gate/outputs 存在性、迭代节点字段。error 非零退出 | `python tools/flow-lint.py [flowId ...]` |
| **export-doc.py** | 小纲/剧本 → Word docx 导出器（内置硬断言：源/导出计数、残渣、集标题；`--plain` 通用模式） | `python tools/export-doc.py <src.md> <out.docx> [--ideas 思路md] [--node <id>] [--expect-episodes N] [--script-format] [--plain]` |

### Stage 封装包管理

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **stage.py** | Stage 包（stage@1）清单/校验/结构树：命名规范、引用完整性、适用品类声明。Stage = 可导入可分发的封装单元，flow 由其拼接 | `python tools/stage.py list`<br>`python tools/stage.py validate [stageId]`<br>`python tools/stage.py tree <stageId>` |

### 内容与知识生产

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **analyze-kakaxing.py** | kakaxing 语料分析：题材×热度、八段式策划案解析、句式与梗族挖掘（确定性、零 LLM）；产出 trope/benchmark 知识条目 | `python tools/analyze-kakaxing.py <语料目录> ...` |
| **worldbook.py** | 世界书脚手架与校验（小说/剧本双变体）：init 生成骨架（不覆盖已有）/ check 索引↔文件一致性 / tree 结构树 | `python tools/worldbook.py init <project> [--variant novel\|drama]`<br>`... check <project>` ｜ `... tree <project>` |

### 项目工具链 vendor（创作者自治）

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **kit.py** | 把项目可独立运行的工具链**拷贝进项目**（kit/ 目录：check-purity/worldbook/export-doc/snapshot/serve + flow.json 快照 + kit.json 溯源账目）。创作者拥有副本、自治版本；上游不自动覆盖 | `python tools/kit.py vendor <project>`<br>`python tools/kit.py status <project>`<br>`python tools/kit.py diff <project> <file>` |

### 基建与呈现

| 工具 | 用途 | 用法 |
| --- | --- | --- |
| **render-flow.py** | flow.json → 图示渲染器：graph.svg + graph.mmd（Obsidian/GitHub 可渲染）+ graphs.html 总览（含世界书体系页签）。flow.json 改动后重跑 | `python tools/render-flow.py [flowId]` |
| **serve.py** | 本地静态服务器（no-store 缓存头，根目录从脚本位置自动反推——杜绝串台）：页面/交付件的预览入口 | `python tools/serve.py [port] [root]`（默认 8420 + 工作区根） |

## 三、内核 CLI 动词（core：`npm run miniflow -- <动词>`，MCP/HTTP 同源）

| 动词 | 职能 | 备注 |
| --- | --- | --- |
| **flow_list** | flow 清单 + 能力索引 | |
| **flow_init** | 生成 项目配置.json 模板（题材/需求/灵感/严肃性/风格/AB 测试/市场预估） | 用户填写后再 flow_run |
| **flow_run** | 开跑：自动装载 项目配置.json、自动迁移旧 run-state.json | 显式入参 > 配置 > flow 默认 |
| **flow_next** | 推进到下一停靠点（就绪批派发）；`--spawn-prompt` 附带派发头 | core 步零 token 就地执行 |
| **flow_submit** | 提交认知步产物：校验 → 落盘 → 注册 → 快照 → journal → 推进 | reject 附定位到条目的失败原因 |
| **flow_resume** | 断点恢复：强制重组任务包（磁盘真相 > 对话记忆） | |
| **flow_gate** | 验收门裁决：pass / pass-with-conditions / send-back（仅本阶段）/ reject；跨阶段须 force | 三重凭据：token+nodeId+round |
| **flow_rerun** | 定向重跑：受影响子图（指纹比对），`--dryRun` 预览范围 | |

> `flow_import`（Zod/Schema 校验的 flow 合成入口）为 M4 规划项。

## 四、维护约定

1. **新增 L1 工具**：标准库 only；文件头 docstring 写清用途与用法；支持 `--help`；登记进本清单（含调用方）。
2. **新增 minitool**：先在 minitool.schema.json 声明（exec + 输入/输出 Schema + 超时），再在 skills 绑定；确定性、零 token、幂等。
3. **命名**：工具名即用途（动宾结构优先）；破坏性变更须升 contracts 版本并在底座规格决策日志记录。
4. **校验链接线**：产物质量类工具（如 check-purity）命中即非零退出，供内核校验链与 CI 调用。
