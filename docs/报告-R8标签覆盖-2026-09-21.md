## 二 · 本轮改了什么

1. **索引搬运修复**（断点③）：`tools/distill-kakaxing.mjs` 索引生成搬运 `tags` / `applies_to`（缺失照缺、不伪造 `["all"]`）。
2. **存量回填**：86 条既有索引按源 md frontmatter 补 `tags`（`tags ∪ routes` 兼容搬运）与 `applies_to`。
3. **梗卡打标**：`kb/trope/*` 13 张补题材标签（重生/复仇/身份错位/北美/狼人/神豪/真假千金……）——
   这是 §2.1 示例池 `kb/trope/*` 的过滤轴，S1-S3 前该池 **0 标签**。
4. **结构母型拆分**（拍板③）：`knowledge/structure/catalog.md` 的 6 母型各自成卡
   （revenge / save-the-cat / ascent / dual-line / barbell-return / episodic-fate），
   带 `tags` + `applies_to`；catalog 本体保留「选型三步 + 节奏对表 + 注入点」并指向六卡。
   下游可按 `decisions/structure.json` 过滤（选「复仇」不必整装六型）。
