## 二 · 恢复动作

1. **解析回收站元数据**（`$I` 文件：8B 版本 + 8B 大小 + 8B 删除时间 + 4B 名字长度 + UTF-16LE 原始路径），
   确认该批次**全部且仅属于 `.git`**，无仓库其他文件被卷入。
2. **按原始路径还原 1108 个文件**（37.4 MB），恢复 `HEAD` / `refs` / `objects` / `config` / `worktrees/*`。
   180 条「失败」记录是**目录条目**（其 `$R` 是目录，不可当文件读），子文件已各自落位。
3. 还原后 `HEAD`、`refs/heads/{main,module-flow-v3,metrics-caliber-d1d5}` 全部可解析。
4. 从 **worktree 索引**用 `git write-tree` **逐字节复现**了 `be6ade4` 的根树 `d4afe60f`
   （树 SHA 是「名字 + 模式 + 内容」的纯函数，因此可确定性重建），并顺带补回 `projects` 子树 `c99069e5`。

## 三 · 残余缺口（**不可精确恢复**）

| 对象 | 类型 | 说明 |
| --- | --- | --- |
| `9fe8653` | commit | WO-03（模块内容重划）。**产物已在 `3691015` 重放**，仅对象本体与 SHA 丢失 |
| `d3bf007` | commit | v3 基线之下的旧提交。产物仍在工作区/悬空对象里，仅对象本体丢失 |
| `d465f7ec` | tree | `docs/` 于 `f424b33` 时的目录树。只影响 `main` 的 `ls-tree -r` / `checkout` |
| `9fbf9852` | tree | `.zcode/plans/` 目录树。索引口径已变（含本次会话新增的 plan 文件），无法复现原 SHA |
| 5 个 blob | blob | 位于上述两棵缺失树内部 |

**为什么补不回来**：这些对象在删除时**被进程占用**，无法进回收站 → 被直接硬删。
`.git/logs`（reflog）在此前已被清空，**拿不到原始 author/committer/时间戳**，
而 commit SHA 含这些元数据，故**无法按原 SHA 重建提交对象**。无远端（`git remote -v` 为空）、
无卷影副本（`vassadmin list shadows` 无可查项）。

**为什么 `git replace` 补不了**：替换要求原对象存在以校验类型，对已丢失对象报
`Objects must be of the same type ... type '(NULL)'`。已存在的（如 `7d8ba7e`，仅父链断）才可替换。

## 四 · 现状与验证

## 五 · 已做的替换（继承自他人，非本次新增）

`refs/replace/7d8ba7e90f7b25f28c54bb7ec7d37d24fbd0660a` → `707e0616`：
把断在缺失提交 `9fe8653` 上的 `7d8ba7e` 嫁接为「父 = `1e7bcf7`」，使 v3 分支祖先链可走。
**`git replace` 是隐式机制**：`git log` 显示的父/边可能与你对原始 SHA 的预期不同，
需要看原始对象时用 `GIT_NO_REPLACE_OBJECTS=1`。撤销：`git replace -d 7d8ba7e90f7b25f28c54bb7ec7d37d24fbd0660a`。

## 六 · 教训 / 建议

1. **先确认删除者**。本次删除用的是「进回收站」API（非 `rm`、非 git），发生在多 agent 并发改同一仓库期间。
   建议：**同一仓库同一时刻只允许一个 agent 执行 git 写操作**，破坏性清理必须走显式确认。
2. **`core/src` 单写权纪律要继续**：本次事故恰好撞在多人并发写 `core/src/kernel.ts` 的窗口上。
3. **加远端是唯一的兜底**。本次无 `origin`，所以丢了就是丢了。建议 `git remote add origin <GitHub>`
   并周期性 `git push --all`（本地 dev 仓库也值得）。
4. 若日后要彻底消掉 `main` 的 `ls-tree -r` 报错，可选其一：**(a)** 接受现状（仅历史浏览受限）；
   **(b)** 用 `git update-ref refs/replace/d465f7ec... <重建树>` 手工写替换 ref（绕过类型校验，属 hack）；
   **(c)** 把 `main` 重指向一个完整提交。
