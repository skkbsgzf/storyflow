# store-draft · Story Science Lab 售卖站初稿

给未来自营售卖站做的初稿：一份可双击打开的**交互原型**（`index.html`）＋这份设计文档。站点定名 **Story Science Lab（故事科学实验室）**，写作工具以 **npm 包＋MCP 服务**开源分发，精修本按部售卖。技术管线复用咔咔猩浏览页验证过的那套：`data JSON → build 脚本 → 数据内嵌的单文件 HTML`，零依赖、离线可用。

## 快速上手

```
node build.mjs        # data/products.json + template.html → index.html
双击 index.html       # 离线查看，无需服务
```

改商品＝改 `data/products.json`，改版式＝改 `template.html`，然后重跑 `node build.mjs`。

## 一、定位：精品工作室，不是超市

咔咔猩的本质是**批发市场**：7938 部剧本、10 个筛选排序控件、133 页翻页。我们的站反着来——货架上的每一件都由工作室署名背书，页面设计目标从「帮你在海量里筛」变成「帮你在一小堆里选」。

| | 咔咔猩（市场） | 本站（工作室） |
|---|---|---|
| 商品数 | 7938 部，持续增长 | 几件到几十件，主动限量 |
| 信任来源 | 平台评级（S/A/A+）、热度 | **公开修订记录**：改了什么、为什么改 |
| 详情页 | 19 项元数据＋平台策划案 | 4 块卖点卡＋试读＋修订日志＋授权条款 |
| 筛选 | 5 筛选器＋5 排序 | 1 行类型标签，完事 |
| 内容 | 平台/AI 生成，批发积分制 | 原创（开源工具免费，精修本收费） |
| 封面 | 平台 AI 图 | 自制「印样」封面＋工作室钤印 |

双引擎逻辑：**开源工具免费**（引流、建立专业信任、SEO/口碑）→ **精修本收费**（变现主体）→ **定制修稿服务**（高客单长尾）。工具即样品：模板做得好，本身就是精修能力的广告。

## 二、商品模型

四类商品，一套字段：

| type | 内容 | 定价参考 | 授权形态 |
|---|---|---|---|
| `script` | 剧本（真人短剧 / AIGC 动画） | ¥199-599/部，单店授权 | 单店排演，一年更新 |
| `short` | 知乎向短篇（0.8-3 万字） | ¥29-99/篇 | 个人阅读；改编授权另议 |
| `novel` | 长篇（分卷，预约制） | 按卷/全本预约 | 个人阅读；出版影视另议 |
| `tool` | 开源模板/工具 | ¥0（MIT） | 开源，可商用可二改 |

**工具是三形态，也是全站引流位**：① **npm/MCP 开源分发**——整个工具箱是一个 npm 包（`npx story-science-lab@latest init`），同时是一个 MCP 服务；主页放「复制配置」按钮，粘贴进 ZCode、CodeBuddy、Cursor 等 AI 编码器的 MCP 设置即完成安装，运行后出现 5 个 `story.*` 工具位（topic/meme/title/beats/deconstruct）。② **在线试玩台**（一句话做选题/造梗/起片名）——MCP 工具的网页版，访客不注册、不留资，输入即出结果、可复制，装之前先玩。③ **MIT 模板模块**（排期表/拆解卡）——GitHub 仓库取用。初稿里试玩台跑本地规则引擎（关键词识别题材＋句式模板），零成本可演示；正式版接大模型 API（Cloudflare Workers＋AI 网关，按量约几厘/次），MCP 服务端同一接口，网页与编码器内体验一致。

**状态机**（status 字段）：`preorder 预售/试读开放` → `on-sale 在售` →（可选）下架绝版。预售价低于完稿价，写作过程本身成为内容（逐章推送）。

**版本与修订**（edition / revisions / changelog）是本站的核心信任资产——每个商品公开修订日志，与「精修工作室」的定位互为证明。这一点刻意继承并放大了咔咔猩「同一部剧换 ID 重新上架」背后的版本意识，但方向相反：他们是掩盖版本，我们是展示版本。

## 三、商品逻辑：从咔咔猩字段到店铺字段

| 咔咔猩字段 | 店铺字段 | 说明 |
|---|---|---|
| `topPlanning` 八段策划案 | `pitch` 四块（一句话卖点/共情点/爽点内核/剧情主线） | 行业验证过的卖点结构，直接复用为商品详情骨架 |
| `logline` | `pitch.logline` | 详情页与列表行共用 |
| `scriptScore` / `scriptGrade` / `topHot` | **不上架展示**，转为内部 `marketNote` 选品依据 | 店铺商品是自己的，无需平台评级背书 |
| `takePoints` 积分售价 | `price` 元 | 自主定价 |
| `topImage` AI 封面 | `cover`（CSS 生成印样＋钤印） | 无图也能上架，视觉统一 |
| `createTime` 上架时间 | `changelog[].date` | 从「平台上新时间」变成「修订时间线」 |
| —（平台没有） | `license` / `delivery` | 精品店必须把授权和交付讲清楚 |

咔咔猩快照的正确用法：**选品与定价研究**（哪个题材在哪个市场 S 级密度高、同行卖多少积分），以及**对标拆解**（开源「桥段拆解卡」模板就是按其策划案结构设计的）。它不是内容来源。

## 四、页面结构（原型已实现）

```
报头：S 钤印＋Story Science Lab＋作品/工具箱/定制修稿导航（文武线）
├─ 首屏：校样式宣言（删除线＋红笔批注，呼应「精修」卖点）
│  ├─ 安装指令条：npx story-science-lab init ＋复制按钮＋MCP 接入入口
│  └─ 本季主推：样书摊开（封面＋卖点＋修订数＋价格＋试读按钮）
├─ 开源工具箱（引流位，紧贴首屏）：
│  ├─ 安装条：CLI 命令＋MCP 配置 JSON，各带「复制」；平台接入行＋说明
│  ├─ 模块网格：5 张模块卡（题/梗/名/拍/拆），MCP 卡带命令示例与「现场试玩」
│  └─ 在线试玩台：一句话做选题 / 造梗 / 起片名，本地实时出结果卡、可复制
├─ 在册作品：书目单（竖排封面行，非卡片墙，只列收费作品）
│  └─ 行点击 → 详情弹层（左：封面＋参数＋授权＋交付；右：四块卖点＋稿纸试读＋修订记录）
├─ 定制修稿：三档服务＋工作室自述＋联系方式
└─ 页脚：示例数据声明＋合规声明＋构建时间
```

视觉方向：**出版校样**。纸白底、铅灰墨字、校对红批注（朱批）、稿纸行线、钤印。记忆点只有一处——首屏被红笔改掉的那行字，直接把「精修」卖点画在脸上；其余一切克制。

## 五、技术架构演进

**Phase 0 — 本稿（已完成）**：单文件静态原型，数据内嵌。验证定位、商品逻辑、视觉方向。

**Phase 1 — MVP 上线（建议 2-4 周，零后端）**：
- 静态站（Cloudflare Pages / GitHub Pages，免费）＋自有域名；本目录直接 `build.mjs` 出站。
- **npm＋MCP 分发落地**：`story-science-lab` 发 npm，`story-science-lab-mcp` 实现 MCP Server（先 stdio＋npx，规则引擎版逻辑直接复用）；主页「复制配置」按钮即真实可用。MCP 目录站（Smithery、mcp.so、Glama、PulseMCP）提交收录，获得自然流量。
- **成交不自建支付**：挂爱发电 / 面包多商品链接，或微信收款＋人工发货（短篇/剧本单价低、频次低，人工完全够）。自站只做橱窗和信任建设。
- 网盘/邮件交付文件包。原型里每个购买按钮的 toast 文案就是这条路径的占位说明。
- **工具试玩台接大模型**：Cloudflare Workers＋AI 网关转发，按量计费（约几厘/次），加基础限流防刷——试玩台是引流主力，值得最先升级。

**Phase 2 — 自动发货（月度订单 >100 再做）**：
- 接聚合支付回调（虎皮椒类）或继续托管平台＋webhook，订单落 SQLite/Supabase。
- 买家凭邮箱取货链接；限购与防盗链（签名 URL，参考咔咔猩 COS 签名地址的教训——过期即失效）。

**Phase 3 — 工作室会员制（远期）**：
- 账户体系、已购更新推送（精修 v2.2 发布 → 老买家自动收到新版，这是和「批发市场」最大的体验差异点）。
- 修订记录公开页可扩展为「作品档案」，成为工作室的作品集与招商业绩。

不做的：评价系统、购物车、优惠券、多商户——超市器件与精品定位冲突。

## 六、合规红线

1. **对外售卖的内容必须原创或已获授权**。咔咔猩抓取数据（含 `topPlanning` 策划案文案）仅用于内部选品与对标分析，不得原文照搬进对外页面或商品。原型的 7 件商品全部为虚构示例。
2. 知乎/盐选内容注意平台独家条款：已签独家的作品不能站外售卖，上架前核对授权链。
3. 剧本类注意与买家的授权边界写清（单店/连锁、年限、二次改编），`license` 字段逐条列明，成交时附书面合同模板。
4. 收款走正规渠道并开票，定制修稿服务尤其需要（对公合作方常要发票）。

## 七、待定决策（需要你拍板）

1. **npm 包名与组织**：`story-science-lab`／`story-science-lab-mcp` 是占位命名，发布前确认 npm 账号与 scope；MCP 工具位命名（`story.topic` 等）发布时改为 MCP 规范的工具名。
2. **首发品类**：建议先用 1-2 部精修剧本＋工具箱冷启动（MCP 工具位引流成本最低），短篇/长篇看知乎侧版权情况。
3. **收款路径**：爱发电/面包多（省事、抽成）vs 微信收款＋人工（灵活、无抽成但全手工）。
4. **定价**：原型里 ¥399/¥299/¥49 是拍的；建议用咔咔猩快照里对标题材的积分售价折算做一个内部定价表再定。

## 设计参考（同类站点套路）

调研过的参照：MCP 目录与安装站（[Smithery](https://smithery.ai)、[LobeHub MCP 目录](https://lobehub.com/mcp)、mcp.so、Glama、PulseMCP）的通用做法——**安装命令＋复制配置 JSON＋平台兼容徽标＋按工具列出能力清单**；[GitHub 官方 MCP Server](https://github.com/github/github-mcp-server) 的 README 模式——每种客户端一行安装命令＋`mcpServers` 配置块＋工具列表表格。本站把这套「工具目录」语言翻译进了校样视觉：黑标签命令行、红章模块字标、MCP/MIT 徽标。
